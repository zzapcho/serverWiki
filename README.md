# ZZAPCHO SERVER WIKI

Minecraft ZZAPCHO SERVER의 공식 가이드 사이트입니다.

- Production: `https://wiki.zzapcho.kr`
- Framework: VitePress
- Deployment: GitHub Pages + GitHub Actions

## Local development

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
npm run docs:preview
```

문서는 `docs/` 아래 Markdown 파일로 관리합니다.
