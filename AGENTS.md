# Instructions for AI coding agents

Before editing this repository, read `AI_README.md` completely and follow it as the project-specific maintenance contract.

- Preserve the theme ownership order: `tokens.css` → `base.css` → `components.css` → `motion.css` → `mobile.css`.
- Keep one complete, always-visible sidebar from `navigation.mts` on every route.
- Treat live server configuration and the current distributed client/JEI data as more authoritative than prose in this repository.
- Do not claim a UI task is complete from a build alone. Run the release gates and visually test the required desktop/mobile widths.
- Do not push or deploy unless the user requested it. When requested, verify the GitHub Pages run and the production URL after deployment.

The full rules, facts, QA matrix, content template, known regressions, and release procedure are in `AI_README.md`.
