# 플레이 콘텐츠 모드

<p class="page-lead">각 모드에서 실제로 무엇이 추가되고, 어떻게 상호작용하며, 별도 단축키가 필요한지를 플레이 기준으로 정리합니다.</p>

## Farmer's Delight Refabricated

<span class="status-chip is-live">사용 중</span>

농사와 요리를 크게 확장합니다. 작물과 음식뿐 아니라 **칼, 도마, 스토브, 프라이팬, 요리 냄비**처럼 조리 과정 자체를 플레이하게 만드는 도구와 블록이 추가됩니다.

### 상호작용

| 대상 | 기본 사용법 | 별도 키 |
|---|---|---|
| 칼 | 조리 재료 손질 및 관련 레시피에 사용 | 없음 |
| 도마 | 재료를 올리고 적절한 도구로 가공 | 없음, 우클릭 중심 |
| 스토브 | 조리 블록의 열원으로 사용 | 없음 |
| 프라이팬 | 조리용 블록/도구로 사용 | 없음 |
| 요리 냄비 | GUI를 열어 여러 재료를 이용한 요리 제작 | 없음 |

정확한 재료와 결과물은 인벤토리 JEI에서 아이템에 마우스를 올린 뒤 `R`을 눌러 확인하세요. 해당 아이템이 어디에 쓰이는지는 `U`입니다.

→ [농사 & 요리 가이드](/guide/farming-cooking) · [조합법](/recipes/)

## Gone Fishing / Go Fish

<span class="status-chip is-beta">베타</span>

기본 낚시 흐름을 유지하면서 추가 어종·보상과 낚시 콘텐츠를 확장합니다.

- 기본 조작은 바닐라와 동일하게 **낚싯대를 던지고 입질에 맞춰 회수**합니다.
- 별도 필수 단축키는 없습니다.
- 획득한 아이템의 제작/용도는 JEI `R` / `U`로 확인합니다.
- 현재 서버 로그에서 **네더/엔드 일부 낚시 전리품 테이블 경고**가 확인되어 해당 차원의 낚시는 정식 오픈 전까지 테스트 대상입니다.

→ [낚시 가이드](/guide/fishing)

## Enchanted Vertical Slabs

<span class="status-chip is-live">사용 중</span>

바닐라 반블록처럼 보이지만 세로 방향으로 설치되는 **세로 반블록**을 추가합니다. 건축에서 얇은 벽, 기둥, 프레임 표현에 유용합니다.

### 조합과 설치

- 바닐라 반블록 레시피를 **세로 방향으로 돌린 형태**로 생각하면 됩니다.
- 같은 재료 블록을 세로 한 줄로 배치하는 패턴을 사용합니다.
- 설치 위치와 바라보는 방향에 따라 원하는 면에 배치합니다.
- 종류에 따라 물과 함께 배치하거나 다른 반블록과 조합되는 동작이 지원될 수 있습니다.

정확한 출력 수량과 해당 재료의 세로 반블록 존재 여부는 JEI에서 확인하세요.

## Skniro's Furniture

<span class="status-chip is-live">사용 중</span>

주방·거실·침실 등에서 사용할 수 있는 가구와 장식 블록을 추가합니다. 일부 블록은 단순 장식이 아니라 수납, 조명, 문처럼 동작합니다.

### 상호작용

- **우클릭**이 기본입니다.
- 수납 기능이 있는 가구는 우클릭으로 보관 UI를 엽니다.
- 일부 조명은 상호작용으로 켜고 끌 수 있습니다.
- 일부 문/슬라이딩 도어는 바닐라 문처럼 상호작용합니다.
- 장식 전용 블록은 별도 기능이 없습니다.

::: warning 재시작 테스트 대상
현재 서버에서 데이터 픽서 관련 경고가 보이므로, 수납형/엔티티형 가구는 오픈 전 **설치 → 아이템 보관 → 서버 재시작 → 유지 확인** 테스트를 진행합니다.
:::

## Friends&Foes

<span class="status-chip is-live">사용 중</span>

과거 Mob Vote 후보를 포함한 여러 몹과 관련 아이템·상호작용을 추가합니다. 별도 메뉴 키보다 **각 몹과 아이템을 직접 사용하는 방식**이 중심입니다.

| 예시 | 플레이어 상호작용 |
|---|---|
| Copper Golem | 구리와 관련된 골렘. 산화 상태를 도끼로 손질하거나 벌집으로 왁스 처리하는 식의 상호작용이 있습니다. |
| Glare | 어두운 장소 탐색과 관련된 행동을 하며 글로우 베리와 상호작용합니다. |
| Rascal | 지하에서 숨바꼭질 형태의 만남과 보상이 있습니다. |
| Tuff Golem | 아이템 전시와 관련된 골렘입니다. |
| Crab | 켈프와 관련된 상호작용 및 전용 아이템이 있습니다. |

모드가 추가하는 모든 몹/아이템의 정확한 레시피와 용도는 JEI 검색을 우선 사용하세요.

## Elytra Slot

<span class="status-chip is-live">사용 중</span>

흉갑을 벗지 않고 겉날개를 동시에 장착할 수 있습니다.

- 인벤토리의 **겉날개 전용 추가 슬롯**에 겉날개를 넣습니다.
- 흉갑 슬롯은 그대로 사용할 수 있습니다.
- 별도 필수 단축키는 없습니다.
- 장착 후 비행 조작은 바닐라 겉날개와 동일합니다.

## Terralith + Tectonic

<span class="status-chip is-live">사용 중</span>

둘 다 조작 메뉴를 추가하는 모드가 아니라 **새 청크가 생성될 때 월드 지형을 바꾸는 계열**입니다.

- Terralith: 오버월드 바이옴과 지형 다양성을 확장합니다.
- Tectonic: 산, 절벽, 강과 대형 지형의 형태를 크게 바꿉니다.
- 별도 키, 조합법, GUI가 없습니다.

기존에 이미 생성된 청크보다 **새로 탐험하는 지역**에서 변화가 잘 보입니다.

## Dungeons and Taverns

<span class="status-chip is-live">사용 중</span>

월드에 바닐라 스타일의 추가 구조물과 던전을 생성합니다.

- 별도 키나 GUI 없음
- 조합법 없음
- 탐험 중 자연스럽게 발견
- 구조물의 상자/몹/장치는 바닐라 방식으로 상호작용
