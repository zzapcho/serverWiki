## 월드 / 탐험

Terralith, Tectonic, Dungeons and Taverns가 **조작 UI 없이 월드 생성 단계에서 자동 적용**됩니다. 기존 청크가 아니라 새로 생성되는 지역에서 변화가 보입니다.

→ [월드 생성 상세](/mods/worldgen) · [탐험 가이드](/guide/exploration)

## 플레이 콘텐츠 공통 사용법

추가 아이템을 처음 보면 다음 순서가 가장 빠릅니다.

1. JEI에서 이름 검색.
2. <kbd>R</kbd>로 제작법 확인.
3. <kbd>U</kbd>로 사용처 확인.
4. 레시피만으로 사용법을 알기 어려우면 이 위키의 모드 상세 페이지 검색.
5. 월드 드롭/낚시/몹 전리품처럼 제작법이 없는 아이템은 획득 경로를 별도로 확인.

→ [조합법 & 제작 흐름](/recipes/)
