# EconomyCraft

<p class="page-lead">가상 화폐를 잔액으로 저장하고 서버 상점, 플레이어 마켓, 직접 판매, 구매 주문을 하나의 거래 흐름으로 묶습니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버 기준

- 현재 서버: `EconomyCraft 1.7.1`.
- Architectury API 기반.
- 일반 플레이어 명령어는 독립 명령어 형태로 사용.
- 관리자 standalone 명령은 꺼두는 방향.
- 잔액 스코어보드는 꺼서 화면을 단순하게 유지.

## 명령어 구조

| 영역 | 명령어 |
|---|---|
| 잔액 | `/bal`, `/bal <플레이어>`, `/bal top` |
| 송금 | `/pay <플레이어> <금액>` |
| 일일 보상 | `/daily` |
| 서버 상점 | `/servershop` |
| 판매 | `/sell [수량|all|everything]` |
| 플레이어 마켓 | `/shop`, `/shop list <가격> [수량]` |
| 주문 | `/orders`, `/orders request ...`, `/orders claim` |

## `/sell`의 중요한 동작

단순히 서버 가격만 보고 판매하지 않습니다. 열린 구매 주문이 더 높은 단가를 제시하면 **가장 잘 쳐주는 주문을 먼저 채우고**, 남는 수량이 서버 매입으로 넘어갈 수 있습니다.

이 때문에 경제가 자연스럽게:

**생산자 → 구매 주문 → 플레이어 거래 → 서버 매입**

순으로 연결됩니다.

## 플레이어 마켓

`/shop list`는 **손에 든 아이템**을 기준으로 등록합니다. 수량을 생략하면 모드가 허용하는 범위 내에서 스택 단위 등록이 가능하므로 등록 직전 아이템과 가격을 확인하세요.

## 주문

```text
/orders request minecraft:diamond 8 2200
```

형태로 구매 요청을 만들 수 있습니다. 가격은 “전체 금액인지 단가인지”를 현재 GUI/명령 도움말에서 다시 확인하고 큰 주문 전에 소량 테스트하는 것이 안전합니다.

## 셜커 거래

EconomyCraft는 채워진 셜커 상자의 내용을 미리 확인하는 기능을 제공할 수 있으며 기본 설명에서는 `Ctrl+Q` 미리보기가 안내됩니다. 다만 클라이언트의 다른 모드 키와 충돌할 수 있으므로 실제 팩에서 현재 동작을 확인하세요.

## 이 서버의 밸런스

- 시작 잔액 500.
- 일일 보상 100.
- 일일 서버 판매 수익 한도 5,000.
- 거래 세율 3%.
- PvP 사망에 따른 직접 잔액 손실 없음.
