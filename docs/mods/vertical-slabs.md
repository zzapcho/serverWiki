# 세로 반블록 · Enchanted Vertical Slabs

Enchanted Vertical Slabs 2.7.0은 바닐라 slab 계열을 **세워서 배치**할 수 있게 합니다. 벽 두께를 반 블록으로 만들거나 기둥/창틀/실내 디테일에 유용합니다.

## 기본 사용

1. 원하는 재료의 세로 반블록을 제작합니다.
2. 일반 블록처럼 들고 원하는 면을 클릭합니다.
3. 클릭한 면/위치에 맞춰 세로 방향으로 배치됩니다.
4. 같은 종류의 세로 반블록을 조합해 바닐라 건축과 섞어 사용합니다.

## 제작법

설치 JAR에는 **146개의 recipe JSON**이 확인됩니다. 가장 일반적인 제작 패턴은 같은 재료 블록 3개를 세로로 쌓아 **세로 반블록 6개**를 얻는 방식입니다.

```text
[재료] [   ] [   ]
[재료] [   ] [   ]   → 세로 반블록 ×6
[재료] [   ] [   ]
```

예: `vertical_stone_slab`은 Stone 3개 세로 배치 → 6개입니다.

## 석재 절단기

돌·안산암·화강암·사암·프리즈머린·딥슬레이트·터프·구리 계열 등에는 stonecutting 레시피도 다수 들어 있습니다. 원재료에서 직접 세로 slab으로 잘라낼 수 있는 항목이 있어 제작대보다 편할 수 있습니다.

## 지원 재료 범위

바닐라 목재 slab 계열, 일반 석재/벽돌/사암/네더/프리즈머린/딥슬레이트/터프, 구리 산화·왁스 계열 등이 포함됩니다. 설치 JAR에는 SimpleOres 호환용 cinnabar 계열 레시피도 들어 있습니다.

## 문제 해결

- 레시피가 기억나지 않으면 `세로반블럭`, `vertical slab`, 재료 이름으로 위키 검색을 사용하세요.
- 특정 재료만 안 만들어지면 일반 slab이 아니라 **원재료 블록**을 요구하는 stonecutting 레시피인지 확인하세요.
- 배치 방향이 원하는 쪽이 아니면 다른 면/블록 모서리를 기준으로 다시 클릭해 보세요.
