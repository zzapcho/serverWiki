# 세로 반블록 · Enchanted Vertical Slabs

바닐라 반블록을 **옆으로 세운 형태**를 추가하는 건축 모드입니다. 새로운 건축 시스템을 배우는 것이 아니라, 반블록 방향 하나가 더 생긴다고 생각하면 됩니다.

## 무엇이 추가되나요?

바닐라에 있는 여러 반블록 재료의 세로형이 추가됩니다. 나무, 돌, 구리 계열처럼 원래 반블록이 있는 재료를 건축에 더 세밀하게 사용할 수 있습니다.

## 제작법

제작대에서 **일반 반블록을 만들 때의 가로 배치를 세로로 돌린 모양**으로 재료를 놓습니다.

```text
[ 재료 ] [     ] [     ]
[ 재료 ] [     ] [     ]
[ 재료 ] [     ] [     ]
```

같은 재료 3개를 세로 한 줄로 배치합니다. 일부 석재 세로 반블록은 석재 절단기에서도 만들 수 있습니다. **정확한 결과 개수와 지원 재료는 현재 서버 버전의 JEI 표시가 최종 기준**입니다.

### JEI에서 바로 확인

1. 인벤토리에서 JEI 검색창에 원하는 재료 이름을 입력합니다.
2. `vertical`, `세로`, 또는 재료 이름으로 결과를 찾습니다.
3. 아이템 위에서 레시피 키를 누릅니다. 기본 배정이 다르면 `설정 → 조작키`에서 JEI를 검색하세요.

## 설치하는 법

1. 만든 세로 반블록을 손에 듭니다.
2. 설치할 블록 면을 바라봅니다.
3. 일반 블록처럼 사용 버튼으로 설치합니다.
4. 바라보는 면과 위치에 따라 왼쪽/오른쪽 절반에 놓입니다.

같은 종류의 세로 반블록을 합치면 바닐라 반블록을 두 개 합치는 것처럼 한 블록으로 결합할 수 있습니다.

## 바닐라와 비슷하게 작동하는 것

- 나무 세로 반블록은 불에 탈 수 있습니다.
- 구리 세로 반블록은 산화될 수 있고 왁스 처리가 가능합니다.
- 전용 단축키는 없습니다.

## 잘 안 놓일 때

원하는 방향과 반대로 놓였다면 블록을 부수기 전에 **다른 면이나 면의 반대쪽 절반을 바라보고 설치**해 보세요. 배치 방향은 별도 회전 키가 아니라 클릭한 위치에 영향을 받습니다.
