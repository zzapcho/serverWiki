# Enchanted Vertical Slabs

<p class="page-lead">바닐라 반블록 재료를 세로 방향으로 쓸 수 있게 해 얇은 벽, 프레임, 기둥 디테일을 크게 늘립니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버 기준

현재 서버는 `2.7.0`을 사용합니다.

## 무엇이 추가되나요?

모드가 지원하는 바닐라 반블록 재료에 대응하는 **별도 세로 반블록 아이템**이 추가됩니다. 일반 반블록을 단순 회전시키는 렌더링 트릭이 아니라 제작/배치 가능한 별도 아이템으로 다룹니다.

## 기본 조합

바닐라 반블록 레시피를 세로로 돌린 형태입니다.

```text
[ 재료 ]
[ 재료 ]
[ 재료 ]
```

일부 석재 계열은 석재 절단기에서도 만들 수 있습니다. 정확한 출력 수량은 현재 JEI 레시피를 확인하세요.

## 설치 / 결합

- 제작한 Vertical Slab 아이템을 들고 원하는 면을 보며 **우클릭**해 설치합니다.
- 같은 계열의 세로 반블록은 바닐라 반블록처럼 결합할 수 있습니다.
- 벽, 유리창, 다른 건축 블록과 만나는 부분은 실제 설치 후 연결 형태를 확인하는 것이 좋습니다.

좌클릭은 일반 블록처럼 채굴하는 입력입니다. 원하는 쪽이 아닌 반대쪽에 붙었다면 억지로 겹치기 전에 한 번 회수하고, 조준한 면과 플레이어 위치를 바꿔 다시 설치하는 편이 안전합니다.

## 실제 건축 루프

1. 사용할 재료의 일반 블록/반블록/세로 반블록을 JEI에서 함께 비교합니다.
2. 한 칸짜리 시험 벽에 방향·결합·텍스처 연결을 먼저 테스트합니다.
3. 불연/산화처럼 재료 특성이 중요한 구역은 작은 표본을 만들어 확인합니다.
4. 본 건축에 적용하고 Furniture 블록과 만나는 면을 마지막에 마감합니다.

## 재료 특성

- 나무 세로 반블록은 불에 탈 수 있습니다.
- 세로 반블록은 연료로 사용할 수 있는 종류가 있습니다.
- 구리 세로 반블록은 일반 구리 블록처럼 산화/왁스 시스템을 따릅니다.

## 건축 활용

| 목적 | 예시 |
|---|---|
| 얇은 벽 | 방 분리, 복도, 외벽 디테일 |
| 창틀 | 한 블록을 다 채우지 않는 프레임 |
| 기둥 | 벽면 돌출/반칸 깊이 표현 |
| 가구 주변 | Furniture 블록과 바닐라 벽 사이 마감 |
| 지붕/외장 | 가로 반블록만으로 안 나오는 수직 깊이 표현 |

별도 단축키는 없습니다.

## 문제 해결

- 조합이 안 보이면 동일 재료의 바닐라 반블록이 존재하는지와 JEI 지원 항목을 확인합니다.
- 결합되지 않으면 두 아이템이 같은 재료/상태인지 확인합니다. 구리의 산화·왁스 상태가 다르면 별개 블록일 수 있습니다.
- 설치 방향이 반복해서 틀리면 조준 면, 플레이어 위치, 인접 블록을 바꿔 단일 블록에서 먼저 재현합니다.
