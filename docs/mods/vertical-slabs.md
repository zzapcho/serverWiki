# 세로 반블록 · Enchanted Vertical Slabs

바닐라 반블록을 **세로로 세운 형태**를 추가합니다. 새로운 진행 시스템이 아니라 건축 선택지를 늘리는 모드라 사용법도 바닐라 반블록과 비슷합니다.

## 무엇이 추가되나요?

바닐라에 반블록이 있는 여러 재료의 세로형이 추가됩니다. 얇은 벽, 기둥 가장자리, 창틀, 가구 표현처럼 한 블록 전체를 쓰기 아까운 공간에 유용합니다.

## 제작법

기본 아이디어는 일반 반블록 제작 모양을 **90도 돌린 세로 한 줄**입니다.

```text
[ 재료 ] [      ] [      ]
[ 재료 ] [      ] [      ]
[ 재료 ] [      ] [      ]
```

같은 재료 3개를 세로로 놓습니다. 일부 석재 계열은 석재 절단기에서도 만들 수 있습니다. 이 서버는 JEI/REI를 쓰지 않으므로 레시피 뷰어 모드가 아니라 **위키의 그림형 조합표**를 기준으로 정리합니다.

## 배치하는 법

1. 세로 반블록을 손에 듭니다.
2. 설치할 블록 면을 바라봅니다.
3. 원하는 절반 쪽을 겨냥해 사용 버튼으로 설치합니다.
4. 반대쪽으로 놓였으면 다른 면이나 면의 반대 절반을 겨냥해 다시 설치합니다.

별도 회전 단축키를 외우는 방식이 아니라 **클릭한 면과 위치**가 방향에 영향을 줍니다.

## 바닐라 성질을 따라가는 것

- 같은 종류의 세로 반블록을 합치면 한 블록으로 결합할 수 있습니다.
- 나무 세로 반블록은 불에 탈 수 있습니다.
- 구리 세로 반블록은 산화되고 왁스 처리를 할 수 있습니다.
- 세로 반블록은 연료로 사용할 수 있는 재료의 성질을 따를 수 있습니다.

## 명령어

플레이어가 사용할 전용 명령어는 없습니다.

## 잘 안 놓일 때

블록 정중앙만 계속 클릭하지 말고 **놓고 싶은 절반 방향으로 커서를 옮겨** 배치해 보세요. 같은 종류 두 개가 합쳐졌다면 일반 반블록을 두 개 겹친 것과 비슷한 상황입니다.
