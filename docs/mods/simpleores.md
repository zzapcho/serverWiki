# 광물 · SimpleOres

광질에 **새 광석 4종과 그 재료를 사용하는 장비·블록**을 더합니다. 바닐라 광질 흐름은 그대로이고, 광산에서 찾을 수 있는 선택지가 늘어납니다.

## 어떤 광물이 있나요?

| 광물 | 어디서 찾나요? | 기본적인 쓰임 |
| --- | --- | --- |
| 주석 (Tin) | 오버월드 | 주석 재료, 장비·블록 제작 |
| 미스릴 (Mythril) | 오버월드 | 미스릴 장비·블록 제작 |
| 아다만티움 (Adamantium) | 오버월드 | 아다만티움 장비·블록 제작 |
| 오닉스 (Onyx) | **네더** | 오닉스 보석과 장비·블록 제작 |

주석·미스릴·아다만티움 광석은 바닐라 광석처럼 원재료 형태를 얻어 가공하는 흐름이고, 오닉스 광석은 보석을 떨어뜨립니다.

::: tip Y좌표를 왜 안 적나요?
월드 생성 설정과 모드 빌드에 따라 세부 생성 범위가 달라질 수 있어 잘못된 숫자를 고정하지 않습니다. 광물의 **차원은 위 표**, 정확한 생성 높이·빈도는 현재 서버 설정이 최종 기준입니다.
:::

## 처음 얻었으면 이렇게 하세요

1. 광석을 채굴합니다.
2. 인벤토리에서 얻은 재료 이름을 확인합니다.
3. JEI 검색창에 `tin`, `mythril`, `adamantium`, `onyx` 또는 한글 이름을 검색합니다.
4. 만들고 싶은 아이템을 선택해 현재 레시피를 확인합니다.
5. 필요한 재료를 모아 바닐라 제작대/화로 흐름처럼 제작합니다.

## 제작법

SimpleOres는 도구, 방어구, 건축 블록 등 **같은 재료에서 파생되는 아이템 수가 많습니다.** 서버에 실제 설치된 빌드와 정확히 맞추기 위해 위키에서 수십 개의 레시피를 고정 복사하지 않고, 이 페이지에서 제작 흐름과 검색어를 안내하고 **세부 3×3 배치는 JEI를 최종 기준**으로 사용합니다.

### 가장 빠른 레시피 확인법

| 만들고 싶은 것 | JEI 검색어 예시 |
| --- | --- |
| 주석 곡괭이 | `tin pickaxe` 또는 `tin` |
| 미스릴 방어구 | `mythril` |
| 아다만티움 도구 | `adamantium` |
| 오닉스 장비 | `onyx` |
| 광물 블록/벽돌류 | 해당 재료 이름 + 결과 아이콘 확인 |

아이템 위에서 **레시피 보기** 키를 누르면 만드는 법, **사용처 보기** 키를 누르면 그 아이템이 재료로 들어가는 제작법을 볼 수 있습니다. 키가 다르면 `설정 → 조작키`에서 JEI 항목을 확인하세요.

## 바닐라와 헷갈리기 쉬운 점

- SimpleOres가 추가하는 것은 단순 장식 광석만이 아니라 관련 도구·방어구·블록까지 포함합니다.
- 오닉스는 오버월드가 아니라 네더에서 찾습니다.
- 클라이언트와 서버의 SimpleOres 버전이 다르면 아이템/레시피 동기화 문제가 생길 수 있습니다. 배포된 클라이언트 모드팩을 그대로 사용하세요.
