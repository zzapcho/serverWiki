# Farmer's Delight Refabricated

<p class="page-lead">농사를 “배고픔 채우기”에서 재료 가공 → 조리 → 음식 → 판매로 이어지는 생활 루프로 확장합니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버 기준

- Minecraft 26.2용 Refabricated 포트 사용.
- 현재 서버 파일: `26.2-3.6.15+refabricated`.
- 정확한 아이템/레시피는 현재 클라이언트 JEI가 최종 기준.

## 핵심 도구와 블록

| 대상 | 역할 | 어떻게 쓰나 |
|---|---|---|
| Knife 계열 | 재료 손질, 일부 드롭/가공 레시피 | JEI가 요구하는 재료/도구 확인 |
| Cutting Board | 재료를 올려 칼/도구로 가공 | 재료를 올린 뒤 요구 도구로 상호작용 |
| Stove | 조리 블록의 열원 | 위에 조리 도구를 배치해 사용 |
| Cooking Pot | 여러 재료를 조합한 요리 | GUI에 재료를 넣고 완성품 회수 |
| Skillet | 직접 가열 조리 | 열원/조리 가능 재료를 JEI에서 확인 |
| 식재료/작물 | 다양한 요리의 입력 | `U`로 어떤 음식에 쓰이는지 확인 |

## 도마 사용 순서

1. 도마를 설치합니다.
2. 가공할 식재료를 도마에 올립니다.
3. 해당 재료의 JEI 레시피를 열어 필요한 도구를 확인합니다.
4. 칼 등 요구 도구로 도마의 재료를 사용합니다.
5. 나온 재료/부산물을 회수합니다.

::: tip `R`만 보지 말고 `U`도 같이
새 작물을 얻었을 때는 그 작물에 <kbd>U</kbd>를 눌러 가능한 요리를 훑는 편이 “무엇을 만들지” 찾기 쉽습니다.
:::

## 요리 냄비 사용 순서

1. 적절한 열원을 준비합니다.
2. Cooking Pot을 설치하고 GUI를 엽니다.
3. 만들 음식에 <kbd>R</kbd>을 눌러 **Cooking Pot 레시피 유형**을 확인합니다.
4. 필요한 재료를 입력 슬롯에 넣습니다.
5. 조리가 진행되는지 확인합니다.
6. 완성품이 그릇/병 등 용기를 요구한다면 출력 조건을 맞춘 뒤 회수합니다.

## 경제에서의 역할

농사와 요리는 반복 가능한 생활형 수입원입니다. 다만 서버 상점에서 재료를 산 뒤 조리해 바로 되팔아 무한 이익이 나지 않도록 **원재료 매입가, 완제품 매입가, 서버 판매가를 함께 조정**합니다.

따라서 “가장 비싼 음식 하나만 자동화”보다 재료 수급, 플레이어 주문, 희귀 식재료 수요를 함께 보는 편이 경제적으로 유리할 수 있습니다.

## 별도 단축키

필수 전용키는 없습니다. 대부분 블록 상호작용과 GUI, JEI `R/U`로 해결합니다.

## 문제가 생길 때

- 서버에서는 Resourceful 계열/전용 서버 환경에서 클라이언트 클래스 관련 경고가 보일 수 있으므로 **실제 기능 고장과 로그 경고를 구분**합니다.
- 레시피가 안 보이면 클라이언트/서버 버전 일치와 JEI 검색을 먼저 확인합니다.
- 조리 블록이 작동하지 않으면 열원, 재료, 출력 용기 조건을 순서대로 확인합니다.
