# 무덤 · Universal Graves

죽었을 때 아이템이 바닥에 흩어져 사라지는 일을 줄이기 위해 **사망 위치에 무덤을 만드는 서버 시스템**입니다.

## 죽으면 어떻게 되나요?

사망하면 무덤이 생성되고, 무덤에는 죽을 때 가지고 있던 아이템과 관련 정보가 보관됩니다. 채팅에 표시되는 위치를 먼저 확인하세요.

## 아이템 회수하기

1. 죽은 위치로 돌아갑니다.
2. 자신의 무덤을 찾습니다.
3. 무덤을 클릭하면 내용을 확인할 수 있습니다.
4. 서버 설정이 허용하는 경우 **빈손으로 Shift + 사용**하면 빠른 회수가 가능합니다.
5. 회수한 뒤 인벤토리가 가득 찼다면 주변에 떨어진 아이템이 없는지도 확인합니다.

## 무덤 위치를 잊었어요

```text
/graves
```

자신의 무덤 목록을 확인하는 기본 명령입니다. 서버 권한에 따라 표시되는 기능은 달라질 수 있습니다.

## 조합법

없습니다. 무덤은 플레이어가 미리 제작하는 아이템이 아니라 **사망 시 서버가 생성하는 보호 시스템**입니다.

## 무덤이 없거나 아이템이 이상할 때

다음 정보를 관리자에게 보내주세요.

- 죽은 대략적인 시각
- 차원: 오버월드 / 네더 / 엔드
- 좌표
- 사망 원인
- 기억나는 주요 아이템
- 가능하면 채팅 또는 무덤 화면 스크린샷

문제가 생긴 상태에서 같은 장소에서 여러 번 죽거나 무덤을 반복해서 부수면 확인이 어려워질 수 있습니다.
