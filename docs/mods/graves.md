# 무덤 · Universal Graves

죽었을 때 아이템과 경험치를 사망 위치의 **무덤에 보관**하는 서버 시스템입니다. 아래 값은 Universal Graves의 기본 설정을 서버에서 따로 바꾸지 않았다는 전제로 설명합니다.

## 죽으면 무엇이 저장되나요?

기본 경험치 저장 방식은 `percent_points` **100%**입니다. 즉 무덤 시스템이 저장 대상으로 받은 경험치 포인트는 기본 설정에서 100% 보관합니다. 아이템도 무덤에 들어가며, 기본값에서는 XP만 있는 무덤을 따로 만드는 기능은 꺼져 있습니다.

## 보호 시간과 만료

| 항목 | 기본값 | 의미 |
| --- | ---: | --- |
| 다른 플레이어 접근 보호 | **900초 = 15분** | 사망 직후 15분 동안 기본적으로 주인 보호 |
| 자동 소멸 | **1800초 = 30분** | 생성 후 30분이 지나면 무덤이 스스로 만료 |
| 만료 시 아이템 드롭 | **켜짐** | 무덤이 만료되면 내용물을 그냥 삭제하지 않고 드롭 |
| 공격자가 보호 우회 | 꺼짐 | PvP 공격자라고 자동으로 무덤을 열 수 없음 |
| 실제 시간 사용 | 꺼짐 | 기본적으로 서버/월드 진행 시간을 기준으로 동작 |
| 플레이어당 무덤 제한 | **없음(-1)** | 기본값에서 개수 제한 없음 |

::: warning 30분은 무덤이 영원히 안전하다는 뜻이 아닙니다
기본값에서는 30분 뒤 무덤 자체가 만료되고 아이템이 바닥에 드롭됩니다. 그 뒤에는 일반 드롭 아이템처럼 위험해질 수 있으므로 가능한 빨리 회수하세요.
:::

## 무덤 찾기와 회수

기본 상호작용 설정은 다음과 같습니다.

- 사망 시 **죽음 나침반 지급: 켜짐**
- 무덤 클릭 시 GUI 열기: **켜짐**
- **빈손 + Shift + 사용** 빠른 회수: 켜짐
- 원격으로 보호 해제: 켜짐
- 원격으로 무덤 부수기: 켜짐
- 원격 잠금 해제 비용 결제: 꺼짐

회수 순서는 `사망 → 위치 확인 → 무덤으로 이동 → 클릭해서 확인 → 필요하면 빈손 Shift+사용`으로 생각하면 됩니다.

## 무덤이 정확한 자리에 못 생기면

기본 배치 설정은 사망 지점 주변 **최대 8블록**에서 빈 위치를 찾습니다. 실패하면 위치를 옮겨 다시 찾는 기능이 켜져 있고, 최대 **5번**, 이동 거리 설정은 **40**입니다. 아무 블록이나 강제로 대체하는 기능은 꺼져 있습니다.

물 위에 띄우는 `generate_on_top_of_fluids`도 기본값은 꺼져 있으므로 물/용암 주변 사망에서는 무덤 위치가 예상과 조금 다를 수 있습니다.

## 플레이어 명령어

```text
/graves
```

**자기 무덤 목록을 여는 기본 플레이어 명령어**입니다. 기본 권한 `universal_graves.list`는 일반 플레이어에게 열려 있습니다.

다른 사람의 무덤 보기, 설정 수정, reload 같은 관리자 기능은 플레이어 가이드에서 제외합니다.

## 아이템이 없거나 무덤이 안 보일 때

1. `/graves`로 자신의 무덤 목록부터 확인합니다.
2. 사망 차원과 좌표를 확인합니다.
3. 사망 지점 바로 그 블록만 보지 말고 주변도 확인합니다. 안전한 배치 위치를 찾으면서 옮겨질 수 있습니다.
4. 30분 이상 지났다면 무덤 만료 후 아이템이 드롭됐을 가능성도 확인합니다.
5. 문제가 의심되면 같은 자리에서 반복 사망하기 전에 사망 시각·좌표·주요 아이템을 관리자에게 전달하세요.

## 조합법

없습니다. 무덤은 제작 아이템이 아니라 사망 시 서버가 생성하는 시스템입니다.
