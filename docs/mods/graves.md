# Universal Graves

<p class="page-lead">사망 아이템을 바닥에 흩뿌리는 대신 무덤에 모아 보관해, 죽음의 위험은 유지하면서 아이템 소실/렉 위험을 줄입니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버 기준

- 현재 서버: `Universal Graves 3.12.0+26.2`.
- 서버 측 모드이며 Polymer 기반 기능을 사용합니다.
- 일반 플레이어는 `/graves` 명령을 사용할 수 있는 구성이 기본입니다.

## 죽었을 때

1. 사망 위치 주변에 무덤이 생성됩니다.
2. 아이템/경험치 처리 방식은 서버의 Graves 설정을 따릅니다.
3. `/graves`를 열어 자신의 무덤 목록을 확인할 수 있습니다.
4. 무덤 위치로 돌아가 상호작용해 회수합니다.

## `/graves`

```text
/graves
```

자신의 무덤 목록을 GUI로 보여주는 메인 명령입니다. 다른 사람의 무덤을 보거나 수정/텔레포트하는 기능은 별도 권한이 필요한 관리자 영역입니다.

## 빠른 회수

Universal Graves에는 설정에 따라 **빈손으로 Shift + 사용**해 빠르게 회수하는 기능이 존재합니다. 하지만 서버 설정에서 켜고 끌 수 있으므로 이 서버에서 실제 활성화됐는지는 일반 클릭/GUI 동작을 먼저 기준으로 확인하세요.

## 무덤을 못 찾으면

- `/graves` 목록 확인.
- 사망 차원 확인.
- 목록에는 있는데 접근이 안 되면 보호/비용 관련 메시지를 기록.
- 아예 무덤이 없다면 사망 원인, 차원, 시간을 관리자에게 전달.

## 인벤세이브권과의 관계

<span class="status-chip is-plan">향후 연동</span>

향후 서버 전용 인벤세이브권은 **먼저 사망 이벤트를 처리해 티켓 1장을 소비하고 인벤토리를 보존**, 티켓이 사용되지 않은 사망만 Graves가 처리하는 구조를 목표로 합니다. 현재는 구현 전이므로 Graves가 기본입니다.
