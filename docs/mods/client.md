# 클라이언트 & QoL 모드

<p class="page-lead">배포 클라이언트에서 플레이 편의, HUD, 지도, 그래픽과 성능을 담당하는 모드입니다. 자동으로 동작하는 모드는 굳이 키를 외울 필요가 없습니다.</p>

## 자주 직접 사용하는 모드

| 모드 | 기능 | 기본 조작 / 찾는 곳 |
|---|---|---|
| JEI | 아이템·레시피·용도 검색 | 아이템 위 `R` = 레시피, `U` = 사용처 |
| JourneyMap | 미니맵·전체 지도·웨이포인트 | `J` 전체 지도, `B` 웨이포인트 |
| Simple Voice Chat | 근거리 음성채팅 | `V` 설정, `Caps Lock` PTT, `M` 음소거, `G` 그룹 |
| Mod Menu | 설치 모드 목록 / 설정 진입 | 메인 메뉴 또는 일시정지 메뉴의 Mod Menu |
| ShulkerBoxTooltip | 셜커 상자 내용 미리보기 | 인벤토리에서 셜커 상자에 마우스를 올림. 세부 키는 설정값에 따름 |
| Mouse Tweaks | 인벤토리 드래그 편의 | 별도 키 없이 마우스 드래그 동작 확장 |
| BetterF3 | F3 화면 가독성 개선 | 바닐라와 동일하게 `F3` |
| Iris | 셰이더 관리 | 비디오 설정의 셰이더 메뉴에서 관리 |

## JourneyMap 기본 키

| 키 | 기능 |
|---|---|
| `J` | 전체 지도 열기 |
| `Ctrl` + `J` | 미니맵 표시 전환 |
| `B` | 현재 위치에 웨이포인트 생성 |
| `Ctrl` + `B` | 웨이포인트 관리자 |
| `\\` | 웨이포인트 표시 목록 |
| `[` / `]` | 지도 엔티티 표시 관련 전환 |
| `Z` | 주변 몹 표시 관련 전환 |
| `+` / `-` | 지도 확대 / 축소 |

기본 키는 다른 모드와 충돌할 수 있습니다. **설정 → 조작 설정 → 키 지정 → JourneyMap**에서 현재 클라이언트의 실제 키를 기준으로 확인하세요.

## Simple Voice Chat 기본 키

| 키 | 기능 |
|---|---|
| `V` | 음성채팅 설정 |
| `Caps Lock` | 푸시투톡 |
| `M` | 마이크 음소거 |
| `G` | 그룹 음성채팅 메뉴 |
| `N` | 음성채팅 기능 활성/비활성 전환 |
| `H` | 음성채팅 아이콘 표시 전환 |

## 자동으로 동작하는 QoL / 그래픽 모드

| 모드 | 하는 일 | 필수 조작 |
|---|---|---|
| AppleSkin | 음식의 허기/포만도 정보를 HUD에 추가 | 없음 |
| BetterAdvancements | 발전과제 화면 개선 | 없음 |
| Chat Heads | 채팅에 플레이어 얼굴 표시 | 없음 |
| Continuity | 연결 텍스처 등 리소스팩 표현 보조 | 없음 |
| Simple Armor HUD | 방어구 상태 HUD | 없음 / 설정 가능 |
| SimpleFog | 안개 표현 조정 | 없음 / 설정 가능 |
| SimpleHUDEnhanced | 추가 HUD 정보 | 설정에 따라 변경 |
| Sodium | 렌더링 성능 개선 | 비디오 설정 |
| Sodium Extra | Sodium 추가 그래픽 옵션 | 비디오 설정 |
| Reese's Sodium Options | Sodium 설정 UI 개선 | 비디오 설정 |
| Lithium | 게임 로직 성능 최적화 | 없음 |
| FerriteCore | 메모리 사용 최적화 | 없음 |
| ImmediatelyFast | GUI/렌더링 일부 최적화 | 없음 |
| Entity Culling | 보이지 않는 엔티티 렌더링 절감 | 없음 |

::: tip 키가 다르면
위 표는 기본값 기준입니다. 클라이언트 모드팩에서 키를 바꿨거나 충돌 해결을 했다면 **현재 Minecraft 조작 설정에 표시되는 값이 최종값**입니다.
:::
