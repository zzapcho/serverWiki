# 클라이언트 & QoL 모드

<p class="page-lead">배포 클라이언트는 “서버 콘텐츠를 맞추는 모드”와 “플레이를 편하게 만드는 모드”가 함께 있습니다. 자동 최적화 모드까지 키를 외울 필요는 없습니다.</p>

## 직접 자주 쓰는 것

| 모드 | 기능 | 핵심 조작 |
|---|---|---|
| JEI | 아이템·레시피·사용처 | 아이템 위 `R` / `U`, 검색창 |
| JourneyMap | 미니맵·전체 지도·웨이포인트 | `J`, 웨이포인트 키는 현재 설정 확인 |
| Simple Voice Chat | 근거리 음성 | `V`, `M`, `N`, `H`, PTT는 사용자 지정 |
| Mod Menu | 설치 모드/설정 진입 | 메뉴의 Mod Menu |
| BetterF3 | F3 정보 가독성 | `F3` |
| ShulkerBoxTooltip | 셜커 내용 미리보기 | 아이템 호버, 세부키 설정 확인 |
| Mouse Tweaks | 인벤토리 마우스 조작 확장 | 드래그/클릭 동작 |
| Iris | 셰이더 로딩/관리 | 비디오/셰이더 설정 |

## 서버 콘텐츠와 맞아야 하는 것

Farmer's Delight, Furniture, Friends&Foes, Elytra Slot처럼 클라이언트에도 레지스트리/화면/리소스가 필요한 콘텐츠는 **서버 배포 팩의 버전**을 우선합니다. 이름만 같은 다른 빌드를 임의로 섞지 마세요.

## Essential

배포 환경에 Essential 관련 로더/구성요소가 보일 수 있지만, **ZZAPCHO SERVER의 인증·멀티플레이 핵심 기능은 Essential에 의존하지 않습니다.** 서버 접속 문제를 해결할 때는 먼저 Fabric 콘텐츠 모드와 서버 배포 팩 일치 여부를 확인하세요.

## 키 충돌의 최종 기준

문서에 적힌 키는 안내용입니다. 실제 키는 항상:

**설정 → 조작 설정 → 키 지정**

에서 확인합니다. 특히 Voice PTT, 그룹 메뉴, JourneyMap 보조 기능은 사용자/팩 설정에 따라 다를 수 있습니다.
