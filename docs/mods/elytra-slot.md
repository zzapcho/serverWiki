# Elytra Slot

<p class="page-lead">이 서버에서는 겉날개 때문에 흉갑을 포기하지 않아도 됩니다. 흉갑과 겉날개를 서로 다른 슬롯에 동시에 장착합니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버에서 원하는 동작

현재 서버는 `Elytra Slot 2.0.0`을 사용하며, 실제 26.2 서버에서 **독립 슬롯 모드로 로드되어 흉갑 + 겉날개 동시 장착**을 사용하고 있습니다.

이 서버의 목적은 “단축키로 흉갑/겉날개를 빠르게 교환”하는 것이 아니라 **둘을 동시에 착용**하는 것입니다.

## 사용법

1. 인벤토리를 엽니다.
2. 추가된 겉날개 전용 슬롯을 찾습니다.
3. Elytra를 그 슬롯에 넣습니다.
4. 일반 흉갑 슬롯에는 흉갑을 그대로 착용합니다.
5. 비행은 바닐라 Elytra와 동일하게 사용합니다.

## 별도 단축키

필수 전용키가 없습니다. 장착은 인벤토리에서 처리합니다.

## 슬롯이 안 보일 때

- 서버 배포 클라이언트에서 Elytra Slot이 실제로 로드됐는지 확인.
- 같은 이름의 다른 Elytra 관련 모드를 임의로 함께 넣지 않았는지 확인.
- Mod Menu에서 로드 목록을 확인.
- 서버와 클라이언트의 콘텐츠 구성을 원래 배포 팩으로 되돌려 테스트.

::: warning 교환형 모드와 중복 설치하지 않기
이 서버는 동시 착용을 위해 Elytra Slot을 선택했습니다. Chestplate/Elytra 자동 교환 모드를 중복으로 넣으면 조작과 장비 상태가 헷갈릴 수 있습니다.
:::
