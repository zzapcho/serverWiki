# Gone Fishing

<p class="page-lead">바닐라 낚싯대 사용감을 유지하면서 추가 어종·전리품·장비·수생 음식과 차원별 낚시를 확장합니다.</p>

<span class="status-chip is-beta">검증 중</span>

## 서버 기준

- 현재 서버: `Gone Fishing 1.12.0+26.2`.
- `FactoryTools 0.11.0+26.2` 의존성이 함께 필요합니다.
- Polymer 기반으로 서버 측 콘텐츠를 제공하는 계열이라 관련 기반 모드를 임의로 제거하면 안 됩니다.

## 무엇이 추가되나요?

- 바이옴/상황에 맞춘 추가 물고기/수생 전리품.
- 새로운 낚싯대와 낚시 관련 장비/트링킷 계열.
- 수생 재료를 이용하는 음식.
- 희귀 loot crate 계열 보상.
- 네더/엔드 전용 낚시 콘텐츠.

## 조작

낚시 자체는 기본적으로 바닐라 흐름입니다.

1. 낚싯대를 물/가능한 낚시 위치에 던집니다.
2. 입질을 기다립니다.
3. 찌 움직임에 맞춰 회수합니다.
4. 새 아이템을 얻으면 JEI에서 <kbd>U</kbd>로 사용처를 봅니다.

별도 필수 단축키는 없습니다.

## 아이템 분류 방법

| JEI 결과 | 의미 |
|---|---|
| `R`에 레시피가 있음 | 직접 제작 가능한 장비/음식/재료일 수 있음 |
| `U`에만 사용처가 있음 | 낚시로 얻어 다른 제작에 쓰는 재료일 가능성 |
| 레시피가 없음 | 낚시/loot crate/월드 획득 전용일 수 있음 |

## 네더 / 엔드 주의

현재 서버 로그에서 네더/엔드 낚시 loot table 일부가 Minecraft 26.2 조건과 맞지 않는 것으로 보이는 파싱 경고가 관찰되었습니다. 따라서:

- 오버월드 낚시 정상 여부와 분리해서 테스트.
- 네더/엔드에서 “아예 보상이 없음 / 특정 전리품만 안 나옴” 같은 증상을 차원별로 기록.
- 모드 업데이트 전에 월드/설정 백업.

이 경고 때문에 **Gone Fishing 전체가 작동하지 않는다고 단정하지는 않습니다.** 문제 범위를 차원별 loot table로 좁혀 검증합니다.

## 경제 활용

일반 물고기/생활 생산물은 반복 수입원이 될 수 있지만, 희귀 crate나 탐험성 전리품을 서버가 무제한 매입하면 수집 가치가 사라집니다. 희귀품은 플레이어 상점/주문 거래를 우선하는 방향이 적합합니다.
