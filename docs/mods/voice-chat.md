# 보이스챗 · Simple Voice Chat

게임 안에서 가까운 플레이어와 음성으로 대화할 수 있게 해 줍니다.

## 가장 먼저 확인할 것

1. `설정 → 조작키`에서 **Simple Voice Chat**을 검색합니다.
2. 보이스챗 설정 화면을 여는 키, PTT(눌러서 말하기), 그룹 관련 키가 어떻게 배정되어 있는지 확인합니다.
3. 마이크 입력 장치와 출력 장치를 확인합니다.

버전과 개인 설정에 따라 키가 달라질 수 있으므로 **특정 PTT 키를 외우는 것보다 현재 조작키 화면을 기준으로 하는 것이 정확합니다.**

## 말이 안 들릴 때

- 마이크가 Windows/운영체제에서 올바르게 선택됐는지 확인
- 게임에서 마이크 음소거 상태인지 확인
- 상대와 너무 멀리 떨어져 있지 않은지 확인
- 보이스챗 연결 아이콘에 오류가 없는지 확인
- 다른 프로그램이 마이크를 독점하고 있지 않은지 확인

## 조합법

없습니다. 보이스챗은 클라이언트와 서버의 통신 기능입니다.

더 자세한 공통 문제 해결은 [Discord & Voice](/community/)를 보세요.
