## 서버 뒤에서 돌아가는 모드

플레이 규칙을 직접 외울 필요는 없지만 안정성/운영에 사용됩니다.

- **성능/월드 처리:** C2ME, Lithium, FerriteCore, Krypton, Noisium, ScalableLux, ServerCore, Chunky, spark
- **복구/감사:** Bkups, Death Backup, Ledger
- **운영/권한:** LuckPerms, UniversalPerms, InvView, FabricProxy Lite
- **라이브러리/호환:** Fabric API, Fabric Language Kotlin, Cloth Config, Collective, BucketLib, Lithostitched, Polymer, Moog's Structure Lib

::: info Death Backup
Death Backup은 사망 직전 인벤토리를 관리자 권한으로 복구하는 운영 도구입니다. 일반 플레이어가 `/deathbackup` 명령을 사용할 기능으로 안내하지 않습니다.
:::

클라이언트 전용 성능/QoL 모드는 [클라이언트 모드](/guide/client)에서 확인하세요.
