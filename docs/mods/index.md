## 현재 플레이에 직접 보이는 주요 모드

| 모드 / 시스템 | 역할 | 범위 | 조작 방식 |
|---|---|---|---|
| Farmer's Delight Refabricated | 농사·요리 확장 | 서버 + 클라이언트 | 블록/도구 상호작용, JEI |
| Gone Fishing / Go Fish | 낚시 콘텐츠 확장 | 서버 중심 | 일반 낚싯대 사용 |
| Enchanted Vertical Slabs | 세로 반블록 | 서버 + 클라이언트 | 설치 방향 / 조합 |
| Skniro's Furniture | 가구·수납·장식 | 서버 + 클라이언트 | 주로 우클릭 |
| Friends&Foes | 추가 몹과 상호작용 | 서버 + 클라이언트 | 몹별 상호작용 |
| Elytra Slot | 흉갑 + 겉날개 동시 착용 | 서버 + 클라이언트 | 인벤토리 추가 슬롯 |
| Terralith + Tectonic | 지형·바이옴 생성 | 월드 생성 | 자동 적용 |
| Dungeons and Taverns | 구조물·던전 | 월드 생성 | 자동 적용 |
| EconomyCraft | 화폐·상점·주문 | 서버 | 명령어 |
| Universal Graves | 사망 무덤 | 서버 | 사망 시 자동 |
| Simple Voice Chat | 근거리 음성채팅 | 서버 + 클라이언트 | 단축키 / 음성 UI |
| Discord Integration / DiscordIO | 채팅·인증·화이트리스트 | 서버/프록시 | Discord + 자동 연동 |
| JEI | 레시피·용도 검색 | 클라이언트 | `R`, `U`, 검색창 |
| JourneyMap | 지도·웨이포인트 | 클라이언트 | `J`, `B` 등 |

::: tip 찾는 기준
모드 이름을 몰라도 됩니다. **“낚시”, “겉날개”, “상점”, “지도”, “레시피”**처럼 하고 싶은 행동을 검색하면 관련 문서가 나오도록 구성합니다.
:::

## 문서 상태

이 페이지는 **서버에 실제로 들어간 주요 기능을 기준으로 한 플레이어용 목록**입니다. 라이브러리·의존성·관리자 전용 최적화 모드는 플레이에 직접 필요할 때만 설명합니다.
