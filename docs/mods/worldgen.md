# 지형 · Terralith + Tectonic

오버월드의 **풍경을 더 다양하게 만드는 두 월드 생성 모드**입니다. 새 조작법을 추가하는 모드가 아니므로 그냥 탐험하면 됩니다.

## 둘이 각각 무엇을 하나요?

### Terralith

바닐라 블록을 이용해 매우 다양한 바이옴과 풍경을 만듭니다. 그래서 새로운 장식 블록을 외우지 않아도 산, 숲, 계곡, 동굴 주변의 분위기가 바닐라보다 다양하게 보입니다.

### Tectonic

바이옴의 종류보다 **땅의 모양과 규모**에 집중합니다. 산맥, 절벽, 계곡 같은 지형이 더 크고 입체적으로 이어질 수 있습니다.

둘이 같이 적용되어 `어떤 바이옴인가`와 `그 땅이 어떤 모양인가`를 동시에 풍부하게 만듭니다.

## 플레이어가 해야 할 것

없습니다. 조합법, GUI, 단축키도 없습니다. 그냥 월드를 탐험하면 됩니다.

## 왜 예전 지역은 평범해 보이나요?

마인크래프트 월드는 한 번 생성된 청크의 지형을 자동으로 새 모드 지형으로 다시 만들지 않습니다. 따라서 **새로 생성되는 청크**에서 현재 월드 생성 구성이 가장 확실하게 나타납니다.

## 광물과는 어떻게 같이 작동하나요?

지형을 탐험하거나 땅을 파는 동안 [SimpleOres](/mods/simpleores)의 광물이 함께 생성될 수 있습니다. 지형 모드 자체가 SimpleOres 장비나 조합법을 바꾸는 것은 아닙니다.

## 조합법

없습니다. Terralith와 Tectonic은 월드 생성 기능입니다.

::: warning 월드 생성 문제를 발견했을 때
끊긴 절벽, 이상한 청크 경계, 생성 중 심한 멈춤이 반복되면 좌표와 스크린샷을 남겨 주세요. 이미 생성된 청크인지 새 청크인지도 함께 알려주면 원인을 찾기 쉽습니다.
:::
