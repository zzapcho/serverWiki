# Skniro's Furniture

<p class="page-lead">바닐라 분위기를 크게 벗어나지 않는 가구·장식 블록을 추가해 실내 공간을 실제 방처럼 꾸밀 수 있게 합니다.</p>

<span class="status-chip is-live">사용 중</span>

## 서버 기준

현재 서버는 `1.5.2-26.2-Fabric`을 사용합니다.

## 가구를 찾는 가장 빠른 방법

1. JEI 검색창에서 `furniture` 또는 원하는 가구 이름을 검색합니다.
2. 아이템 위에서 <kbd>R</kbd>로 제작법을 봅니다.
3. 제작 후 설치합니다.
4. **우클릭**해 기능이 있는 가구인지 확인합니다.

## 가구 유형

| 유형 | 플레이 방식 |
|---|---|
| 장식 | 설치/배치 방향과 조합이 핵심 |
| Storage | 우클릭해 보관 UI가 있는지 확인 |
| 개폐/문 계열 | 일반 문/수납 블록처럼 상호작용 |
| 조명/상태 변화 | 우클릭으로 상태가 바뀌는지 확인 |

모든 가구가 기능성 블록은 아닙니다. 모양은 비슷해도 일부는 순수 장식일 수 있습니다.

## 실제 상호작용

| 입력 | 기대하는 동작 |
|---|---|
| 가구를 들고 우클릭 | 조준한 면에 배치 |
| 빈손/아이템을 들고 우클릭 | 수납 UI, 개폐, 조명/상태 전환 등 해당 가구 기능 확인 |
| 좌클릭 | 일반적으로 가구 채굴/파괴 시작 |

기능이 없는 장식 가구는 우클릭해도 변화가 없을 수 있습니다. 이름과 모양이 비슷한 다른 변형을 JEI에서 확인하세요.

## 대표 제작·획득 흐름

가구마다 재료와 출력 수량이 달라 수작업 목록보다 현재 JEI가 정확합니다. 원하는 방의 테마를 먼저 정한 뒤 JEI에서 가구 이름/재료를 검색하고, 한 개를 시험 제작해 크기·방향·상호작용을 확인한 다음 묶음 제작하세요.

## 배치 팁

- 큰 벽/바닥은 바닐라 블록으로 먼저 잡습니다.
- Vertical Slabs로 벽 두께와 파티션을 정리합니다.
- 가구는 마지막에 넣어 동선과 상호작용 공간을 확보합니다.
- 수납 가구 앞에는 클릭 가능한 면을 다른 장식으로 막지 않습니다.

## 중요한 검증 항목

현재 서버 로그에는 이 모드의 여러 요소에 대해 **data fixer 등록 관련 경고**가 보인 적이 있습니다. 서버가 부팅된다는 것만으로 저장 안정성을 확정하지 않습니다.

수납/엔티티형 가구는 다음 테스트를 우선합니다.

1. 가구 설치.
2. 가능하면 아이템 보관/상태 변경.
3. 서버 정상 재시작.
4. 같은 위치에서 블록/내용/상태 유지 확인.
5. 이상이 있으면 좌표와 가구 이름을 기록.

::: warning 중요한 아이템 장기 보관
수납형 가구의 재시작 유지 테스트가 충분히 끝나기 전에는 유일한 희귀 아이템을 한 곳에만 보관하지 않는 것이 안전합니다.
:::

별도 필수 단축키는 없습니다.

## 문제 해결

- 우클릭해도 반응이 없으면 장식 전용인지, 클릭 면이 다른 장식에 가려졌는지 확인합니다.
- 수납 내용/상태가 재시작 후 바뀌면 가구 이름, 좌표, 차원, 재시작 전후 상태를 기록합니다.
- 잘못된 모양이나 투명 텍스처는 배포 리소스팩/클라이언트 모드 구성을 원본과 비교합니다.
- data fixer 경고는 알려진 운영 이슈입니다. 검증 전 수납형 가구를 유일한 희귀품 보관소로 쓰지 마세요.
