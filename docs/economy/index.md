## 화폐

현재 경제의 기본 단위와 수입/지출 구조를 이곳에 정리합니다.

## 상점

서버 상점은 경제에 돈을 공급하고 회수하는 역할을 하고, 플레이어 상점은 유저 간 거래를 담당합니다.

## 수표

<span class="status-chip">설계 예정</span>

금액을 아이템으로 바꿔 보관하거나 다른 플레이어에게 전달할 수 있는 기능을 계획하고 있습니다.

## 인벤세이브권

<span class="status-chip">설계 예정</span>

사망 시 일정 조건에서 인벤토리를 보호하는 서버 고유 시스템으로 제작할 예정입니다.

::: warning
가격과 세부 규칙은 아직 최종 밸런싱 전입니다. 실제 오픈 전 문서에서 확정값만 표시합니다.
:::
