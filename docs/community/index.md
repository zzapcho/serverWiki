# Discord & Voice

서버의 Discord 연동과 인게임 음성채팅 사용법을 정리합니다.

## Discord

- 서버 인증 / 화이트리스트
- Minecraft ↔ Discord 채팅 연동
- 서버 상태 메시지
- 접속 / 퇴장 / 사망 / 발전과제 알림

## 음성채팅

Simple Voice Chat을 사용해 서버 안에서 근거리 음성채팅을 사용할 수 있습니다.

### 기본 확인

1. 클라이언트에 음성채팅 모드가 설치되어 있는지 확인
2. `V` 키로 음성채팅 설정 열기
3. 올바른 마이크와 출력 장치 선택
4. 서버 접속 후 연결 상태 확인

::: info
최종 버전에서는 Discord 인증 과정과 음성채팅 문제 해결을 스크린샷과 함께 추가할 예정입니다.
:::
