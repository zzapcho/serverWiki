# Discord & Voice

<p class="page-lead">서버 밖에서는 Discord, 서버 안에서는 Minecraft 채팅과 근거리 음성채팅이 자연스럽게 이어지도록 구성되어 있습니다.</p>

## Discord 인증

<span class="status-chip is-live">사용 중</span>

서버 입장 권한은 Discord에서 인증/화이트리스트 절차를 통해 관리합니다. 인증이 완료되면 해당 Minecraft 계정으로 서버에 접속할 수 있습니다.

::: tip 인증이 안 먹으면
Minecraft 닉네임을 정확히 입력했는지, Discord에서 인증이 완료되었다는 안내가 나왔는지 먼저 확인하세요.
:::

## Minecraft ↔ Discord 채팅

<span class="status-chip is-live">사용 중</span>

Minecraft에서 보낸 채팅은 Discord 채널로 전달되고, Discord에서 보낸 메시지도 게임 안에서 확인할 수 있습니다.

Minecraft 플레이어의 메시지는 Discord에서 **Minecraft 닉네임과 스킨 아바타**를 사용해 표시되도록 서버가 패치되어 있습니다.

서버 시작/종료, 접속/퇴장, 사망, 발전과제 등의 이벤트도 Discord에서 확인할 수 있습니다.

## Simple Voice Chat

<span class="status-chip is-live">사용 중</span>

서버 안에서는 Simple Voice Chat을 이용한 근거리 음성채팅을 사용할 수 있습니다.

### 처음 설정

1. 서버 접속
2. <kbd>V</kbd>로 Voice Chat 설정 열기
3. 마이크/출력 장치 선택
4. 입력 레벨과 볼륨 조절
5. 다른 플레이어 근처에서 연결 테스트

PTT 키는 사용자의 클라이언트 설정에 따라 달라질 수 있으므로 Voice Chat 설정 화면에서 확인하세요.

## 음성채팅이 안 들릴 때

- 운영체제에서 Minecraft/Java의 마이크 권한 확인
- Voice Chat에서 올바른 입력/출력 장치 선택
- 마이크 음소거 여부 확인
- 클라이언트에 서버와 맞는 Simple Voice Chat 버전이 설치됐는지 확인

문제가 계속되면 [문제 해결](/troubleshooting/) 페이지를 확인하세요.
