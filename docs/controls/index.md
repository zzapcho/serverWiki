## 전체 단축키 표

| 기능 / 모드 | 기본 키 | 설명 |
|---|---|---|
| Simple Voice Chat 설정 | `V` | 마이크, 볼륨, 입출력 장치 등을 설정 |
| Simple Voice Chat 푸시투톡 | `Caps Lock` | 누르고 있는 동안 말하기 |
| Simple Voice Chat 음소거 | `M` | 내 마이크 음소거 전환 |
| Simple Voice Chat 그룹 | `G` | 그룹 음성채팅 메뉴 |
| Simple Voice Chat 켜기/끄기 | `N` | 음성채팅 기능 전환 |
| Simple Voice Chat 아이콘 | `H` | 화면 음성 아이콘 전환 |
| JourneyMap 전체 지도 | `J` | 전체 지도 열기 |
| JourneyMap 미니맵 | `Ctrl` + `J` | 미니맵 표시 전환 |
| JourneyMap 웨이포인트 | `B` | 현재 위치 웨이포인트 생성 |
| JourneyMap 웨이포인트 관리 | `Ctrl` + `B` | 웨이포인트 관리자 열기 |
| JourneyMap 확대/축소 | `+` / `-` | 지도 줌 변경 |
| JEI 레시피 | 아이템 위 `R` | 선택한 아이템의 제작법 보기 |
| JEI 사용처 | 아이템 위 `U` | 선택한 아이템이 들어가는 레시피 보기 |
| BetterF3 | `F3` | 개선된 디버그 화면 |
| 가구 상호작용 | `우클릭` | 수납, 조명, 문 등 지원 기능 사용 |
| Farmer's Delight 작업대 | `우클릭` | 도마/냄비 등과 상호작용 |
| Elytra Slot | 인벤토리 | 추가 겉날개 슬롯에 장착. 전용 키 없음 |
| Mouse Tweaks | 마우스 드래그 | 인벤토리 드래그/분배를 자동 확장 |
| ShulkerBoxTooltip | 아이템에 마우스 올리기 | 셜커 내용 미리보기. 세부 키는 설정값에 따름 |

## 키 충돌 해결

1. **설정 → 조작 설정 → 키 지정**으로 이동합니다.
2. 충돌로 표시되는 키를 확인합니다.
3. `V`, `J`, `B`, `R`, `U`처럼 자주 쓰는 키를 우선 유지합니다.
4. 거의 쓰지 않는 클라이언트 기능을 다른 키로 이동합니다.

::: warning R / U가 입력창에 찍힐 때
JEI 단축키는 **아이템 위에 마우스를 올린 상태**에서 사용해야 합니다. 채팅이나 검색창에 커서가 들어가 있으면 문자 입력으로 처리될 수 있습니다.
:::

## 자동 기능은 키가 없습니다

AppleSkin, Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, Continuity, Chat Heads 같은 모드는 대부분 자동 적용되거나 설정 화면에서만 조정합니다. 모든 설치 모드를 키 하나씩 외울 필요는 없습니다.
