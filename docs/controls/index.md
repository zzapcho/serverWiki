# 조작법 & 단축키

이 서버는 전용 키를 많이 추가하지 않습니다. **키가 기억나지 않으면 `설정 → 조작키`에서 모드 이름을 검색하는 것이 가장 빠릅니다.**

## 꼭 알아둘 것

| 기능 | 조작 |
| --- | --- |
| 세로 반블록 | 전용 키 없음. 일반 블록처럼 설치 |
| SimpleOres | 전용 핵심 키 없음. 아이템/레시피는 JEI 사용 |
| 계절 | 전용 플레이 키 없음 |
| Terralith / Tectonic / MES | 전용 키 없음 |
| 무덤 | 클릭하여 확인, 설정에 따라 빈손 Shift + 사용으로 빠른 회수 가능 |
| 보이스챗 | 현재 `설정 → 조작키 → Simple Voice Chat` 확인 |
| JEI | 현재 `설정 → 조작키 → JEI` 확인 |

## JEI

레시피를 찾을 때 가장 많이 씁니다.

- 아이템 이름 검색 → 해당 아이템 찾기
- 레시피 보기 → 만드는 법 확인
- 사용처 보기 → 그 재료가 들어가는 제작법 확인

`R` / `U`가 흔히 사용되지만 **현재 클라이언트 키 설정이 최종 기준**입니다.

## 보이스챗

PTT, 음소거, 설정 화면, 그룹 관련 키는 버전/개인 설정에 따라 달라질 수 있습니다. 예전 인터넷 글에 적힌 기본키를 그대로 믿지 말고 조작키 화면에서 `Simple Voice Chat`을 검색하세요.

## 키가 겹칠 때

1. `설정 → 조작키`를 엽니다.
2. 빨간색 또는 충돌 표시가 있는 키를 확인합니다.
3. 자주 쓰는 기능부터 편한 키로 다시 지정합니다.
4. 모드 이름으로 검색하면 관련 키만 빠르게 찾을 수 있습니다.
