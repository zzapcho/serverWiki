# 조작법 & 단축키

<p class="page-lead">서버에서 자주 쓰는 조작만 모았습니다. 클라이언트 설정을 직접 바꿨다면 실제 키는 다를 수 있습니다.</p>

## 가장 자주 쓰는 것

| 기능 | 기본 키/조작 | 설명 |
|---|---|---|
| 음성채팅 설정 | `V` | 마이크, 볼륨, 입력/출력 장치 등을 설정합니다. |
| 전체 지도 | `J` | JourneyMap 전체 지도를 엽니다. |
| JEI 레시피 | `R` | 아이템 위에서 레시피를 확인합니다. 기본 설정 기준입니다. |
| JEI 사용처 | `U` | 아이템이 어디에 쓰이는지 확인합니다. 기본 설정 기준입니다. |
| 가구 상호작용 | `우클릭` | 가구 사용, 앉기, 열기 등에 사용합니다. |
| 겉날개 슬롯 | 인벤토리 | 흉갑과 별도 슬롯에 겉날개를 장착합니다. |
| 기본 디버그 | `F3` | Minecraft 디버그 정보를 표시합니다. |

## Simple Voice Chat

Voice Chat 설정 화면은 <kbd>V</kbd>로 엽니다. 여기서 마이크 장치, 출력 장치, 볼륨, 활성화 방식 등을 먼저 확인하세요.

PTT(눌러서 말하기) 키는 클라이언트 설정에 따라 달라질 수 있으므로 **Voice Chat 설정 화면에서 현재 키를 확인**하는 것을 권장합니다.

## JEI

JEI는 별도 메뉴보다 **인벤토리 화면 안에서 검색**하는 방식으로 자주 사용합니다.

- 검색창: 아이템 이름으로 검색
- <kbd>R</kbd>: 제작/획득 레시피
- <kbd>U</kbd>: 사용처

모드 아이템 이름을 정확히 모를 때도 일부 단어만 입력해 찾을 수 있습니다.

## JourneyMap

<kbd>J</kbd>를 눌러 전체 지도를 열 수 있습니다. 장거리 탐험에서는 중요한 장소를 웨이포인트로 저장해두는 것을 권장합니다.

## 키가 겹칠 때

1. Minecraft **설정 → 조작 설정**으로 이동합니다.
2. 충돌 표시가 있는 키를 찾습니다.
3. 자주 쓰는 기능의 키는 유지하고, 덜 쓰는 기능을 다른 키로 옮깁니다.
4. 바꾼 키는 친구들과 공유하지 않아도 되지만, 문제 해결 요청 시 본인이 변경했다는 점을 알려주세요.

::: tip 검색 단축키도 있습니다
이 위키에서는 <kbd>Ctrl</kbd> + <kbd>K</kbd> 또는 <kbd>/</kbd>로 바로 문서 검색을 열 수 있습니다.
:::
