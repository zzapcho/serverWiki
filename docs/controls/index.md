## Voice Chat은 왜 PTT 키가 표에 없나요?

현재 Simple Voice Chat에서는 **PTT가 기본 고정키로 묶여 있지 않고 온보딩에서 직접 선택**합니다. 그룹 채팅 키도 최신 Minecraft 계열에서는 기본 미지정입니다. 따라서 `Caps Lock`, `G` 같은 값을 서버 표준 기본키처럼 외우면 오히려 친구마다 설정이 달라져 혼란이 생깁니다.

→ [Simple Voice Chat 상세](/mods/voice-chat)

## JourneyMap 키가 다를 때

JourneyMap은 여러 기능에 키를 배정할 수 있고 다른 모드와 충돌할 수 있습니다. 이 서버에서 중요한 것은 **전체 지도와 웨이포인트**입니다. 나머지 줌/레이더/웨이포인트 관리자 같은 보조키는 다음 위치에서 현재 값을 확인하세요.

**설정 → 조작 설정 → 키 지정 → JourneyMap**

## 키 충돌 해결 순서

1. **설정 → 조작 설정 → 키 지정**으로 이동합니다.
2. 빨간색/충돌 표시된 키를 확인합니다.
3. `V`, `J`, `B`, JEI `R/U`처럼 자주 쓰는 기능을 우선 보존합니다.
4. 거의 쓰지 않는 HUD/지도 보조 기능을 다른 키로 이동합니다.
5. Voice PTT는 채팅, 달리기, 인벤토리 조작과 겹치지 않는 키로 직접 지정합니다.

::: warning R / U가 그냥 글자로 입력될 때
JEI 키는 **아이템 스택 위에 마우스를 올린 상태**에서 사용해야 합니다. 채팅창이나 검색 입력칸에 포커스가 있으면 정상적으로 문자 입력이 됩니다.
:::
