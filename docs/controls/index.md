# 조작법 & 단축키

서버에서 자주 쓰는 조작과 모드 단축키를 한 곳에 모읍니다.

## 빠른 단축키 표

| 기능 | 기본 키 | 설명 |
|---|---|---|
| 음성채팅 설정 | `V` | 마이크, 볼륨, 입력 장치 등을 설정합니다. |
| 전체 지도 | `J` | JourneyMap 전체 지도를 엽니다. |
| 레시피 검색 | 인벤토리 | JEI에서 아이템과 제작법을 검색합니다. |
| 가구 상호작용 | `우클릭` | 가구 열기, 사용, 앉기 등에 사용합니다. |
| 겉날개 슬롯 | 인벤토리 | 흉갑과 별도로 겉날개를 장착합니다. |

## 키가 겹칠 때

Minecraft 설정의 **조작 설정**에서 충돌하는 키를 확인한 뒤, 자주 쓰지 않는 기능부터 다른 키로 바꾸는 것을 권장합니다.

::: info
최종 버전에서는 실제 배포 클라이언트 기준으로 모든 단축키를 다시 확인한 뒤 표를 확정합니다.
:::
