## 죽었을 때

1. 아이템이 일반적으로 **Universal Graves 무덤**에 보관됩니다.
2. `/graves`로 자신의 무덤 목록을 확인할 수 있습니다.
3. 사망 위치로 돌아가 무덤을 열고 아이템을 회수합니다.
4. 향후 인벤세이브권이 구현되기 전까지는 무덤이 기본 규칙입니다.

## Voice Chat

- <kbd>V</kbd>: Voice Chat GUI. 첫 실행 시 마이크/스피커와 말하기 방식을 설정합니다.
- <kbd>M</kbd>: Voice Activation 모드에서 마이크 음소거 전환.
- <kbd>N</kbd>: 음성채팅 전체 활성/비활성 전환.
- <kbd>H</kbd>: 음성채팅 아이콘 표시 전환.
- **PTT 키와 그룹 메뉴는 현재 버전에서 기본 고정키가 아닙니다.** 설정/온보딩에서 직접 지정하세요.

→ [Simple Voice Chat](/mods/voice-chat)

## 모드 아이템을 처음 봤을 때

1. JEI 검색창에 이름 일부 입력.
2. 제작하고 싶으면 아이템 위에서 <kbd>R</kbd>.
3. 어디에 쓰는지 궁금하면 <kbd>U</kbd>.
4. 도마·요리 냄비·무덤·가구처럼 **상호작용 방식 자체가 특수한 경우** [모드 상세](/mods/)에서 확인.

## 가장 자주 생기는 문제

- 접속 실패 → 서버 배포 클라이언트와 버전/모드 구성 비교.
- Voice 연결은 되는데 안 들림 → 입력/출력 장치와 음소거 확인.
- 키가 다름 → Minecraft **설정 → 조작 설정 → 키 지정**이 최종 기준.
- 네더/엔드 낚시 이상 → 현재 알려진 Gone Fishing 이슈일 수 있음.
- 가구가 재시작 후 이상 → 위치와 아이템 이름을 관리자에게 전달.

→ [문제 해결](/troubleshooting/)
