# 명령어

ZZAPCHO SERVER에서 사용할 수 있는 명령어를 기능별로 정리합니다.

## 빠른 도움말

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/wiki` | 서버 위키 링크를 엽니다. | 계획 |
| `/guide` | 서버 가이드를 엽니다. | 계획 |
| `/commands` | 명령어 안내를 엽니다. | 계획 |
| `/bal` | 현재 보유 금액을 확인합니다. | 사용 |
| `/pay <플레이어> <금액>` | 다른 플레이어에게 돈을 보냅니다. | 사용 |
| `/daily` | 일일 보상을 확인/수령합니다. | 사용 |
| `/shop` | 플레이어 상점 기능을 사용합니다. | 사용 |
| `/orders` | 주문/거래 기능을 확인합니다. | 사용 |

## 문서 구성 방식

최종 버전에서는 각 명령어마다 아래 내용을 표시합니다.

- 정확한 사용 형식
- 필요한 권한
- 예시
- 쿨타임 또는 제한
- 관련 기능 링크

::: tip
명령어는 '모드별'이 아니라 플레이어가 찾기 쉬운 '기능별'로 정리할 예정입니다.
:::
