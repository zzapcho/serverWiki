# 전체 명령어

<p class="page-lead">일반 플레이어가 실제로 사용할 수 있는 명령어를 기능별로 정리합니다. 명령어 표의 복사 버튼은 가로 스크롤이 필요한 표에서도 키보드로 접근할 수 있습니다.</p>

## 경제

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/bal` | 내 잔액 확인 | 사용 중 |
| `/bal <플레이어>` | 해당 플레이어 잔액 확인 | 사용 중 |
| `/bal top` | 잔액 상위 목록 확인 | 사용 중 |
| `/pay <플레이어> <금액>` | 다른 플레이어에게 송금 | 사용 중 |
| `/daily` | 일일 보상 수령 | 사용 중 |
| `/servershop` | 서버 관리 상점 열기 | 사용 중 |
| `/sell` | 손에 든 아이템을 판매 | 사용 중 |
| `/sell <수량>` | 손에 든 아이템을 지정 수량만 판매 | 사용 중 |
| `/sell all` | 인벤토리의 같은 아이템을 모두 판매 | 사용 중 |
| `/sell everything` | 판매 가능한 인벤토리 아이템을 일괄 판매 | 사용 중 |
| `/shop` | 플레이어 마켓 열기 | 사용 중 |
| `/shop list <가격> [수량]` | 손 아이템을 지정 가격으로 등록 | 사용 중 |
| `/orders` | 구매 주문 목록 열기 | 사용 중 |
| `/orders request <아이템> <수량> <가격>` | 아이템 구매 주문 생성 | 사용 중 |
| `/orders claim` | 오프라인 중 거래된 아이템 수령 | 사용 중 |

::: info `/sell`과 주문의 관계
열린 구매 주문이 서버 매입가보다 더 높은 단가를 제시하면 EconomyCraft는 **더 높은 주문부터 우선 충족**하고, 남는 물량을 서버 가격으로 처리할 수 있습니다. 판매 전 가격을 확인하면 플레이어 거래가 더 유리할 수 있습니다.
:::

## 무덤

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/graves` | 자신의 무덤 목록 GUI 확인 | 사용 중 |

다른 플레이어 무덤 관리, 원격 수정/관리 명령은 권한이 필요한 관리자 범위라 일반 목록에서 제외합니다.

## Voice Chat

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/voicechat help` | 사용할 수 있는 Voice Chat 명령 확인 | 사용 중 |
| `/voicechat invite <플레이어>` | 현재 그룹에 플레이어 초대 | 사용 중 |
| `/voicechat join <그룹이름>` | 이름이 유일한 그룹에 참여 | 사용 중 |
| `/voicechat leave` | 현재 그룹에서 나가기 | 사용 중 |

`/voicechat test <플레이어>`는 관리자 권한이 필요한 진단 명령입니다.

## 서버 도움말

아래 명령어는 서버 전용 Core와 함께 추가할 계획입니다. **아직 현재 기능으로 착각하지 마세요.**

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/wiki` | 이 위키의 홈 링크 표시 | 계획 |
| `/guide` | 서버 가이드 링크 표시 | 계획 |
| `/commands` | 명령어 문서 링크 표시 | 계획 |

## 예시

```text
/pay zzapcho 500
/shop list 250 16
/orders request minecraft:diamond 8 2200
/sell all
```

## 명령어가 안 될 때

- `<플레이어>`, `<금액>` 같은 표기 부분을 실제 값으로 바꿨는지 확인
- 해당 시스템이 서버 설정에서 활성화되어 있는지 확인
- 권한이 필요한 관리자 명령어가 아닌지 확인
- 탭 자동완성에 명령어가 보이는지 확인
- 업데이트 직후라면 [업데이트](/changelog/)와 [문제 해결](/troubleshooting/) 확인

::: warning 송금은 실행 전 대상과 금액을 다시 확인
`/pay`는 실행하면 실제 잔액이 이동합니다. 닉네임 자동완성과 숫자를 확인하고 실행하세요.
:::
