# 명령어

<p class="page-lead">플레이어가 실제로 자주 쓰는 명령어를 기능별로 정리합니다. 명령어 옆의 **복사** 버튼을 누르면 그대로 클립보드에 들어갑니다.</p>

## 경제

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/bal` | 현재 보유 잔액을 확인합니다. | 사용 중 |
| `/pay <플레이어> <금액>` | 다른 플레이어에게 돈을 보냅니다. | 사용 중 |
| `/daily` | 일일 보상을 수령합니다. | 사용 중 |
| `/servershop` | 서버 상점 기능을 엽니다. | 사용 중 |
| `/sell` | 서버 판매 기능을 사용합니다. | 사용 중 |
| `/shop` | 플레이어 상점 기능을 사용합니다. | 사용 중 |
| `/shop list <가격> [수량]` | 손에 든 아이템을 지정 가격으로 상점에 등록합니다. | 사용 중 |
| `/orders` | 주문/거래 기능을 확인합니다. | 사용 중 |

### 예시

```text
/pay zzapcho 500
/shop list 250 16
```

::: warning 돈을 보낼 때 닉네임과 금액 확인
`/pay`는 실행 즉시 잔액이 이동할 수 있으므로 보내기 전에 대상과 금액을 다시 확인하세요.
:::

## Discord

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/discord` | 서버 Discord 안내 메시지/초대 링크를 표시합니다. | 사용 중 |

## 서버 도움말

아래 명령어는 서버 전용 Core 기능과 함께 추가할 계획입니다.

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/wiki` | 이 위키의 홈을 엽니다. | 계획 |
| `/guide` | 서버 가이드 링크를 표시합니다. | 계획 |
| `/commands` | 명령어 문서 링크를 표시합니다. | 계획 |

## 명령어가 안 될 때

- 철자와 `/` 포함 여부 확인
- `<플레이어>`, `<금액>` 같은 부분을 실제 값으로 바꿨는지 확인
- 권한이 필요한 관리자 명령어가 아닌지 확인
- 서버 업데이트 직후라면 [업데이트](/changelog/) 또는 Discord 공지를 확인

::: info 관리자 명령어는 공개 목록에서 제외합니다
이 페이지는 일반 플레이어가 사용하는 명령어를 기준으로 유지합니다.
:::
