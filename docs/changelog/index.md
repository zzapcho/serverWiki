# 업데이트

플레이어가 알아야 할 변화만 정리합니다. 내부 라이브러리의 작은 버전 변경까지 모두 적는 개발 로그는 아닙니다.

## 2026-08-17 · Vanilla+ 문서 재정리

- `처음 접속하기`, `30초 빠른 참조`와 시작하기 메뉴를 제거했습니다.
- 서버 방향을 **바닐라 최대 유지 + 필요한 기능만 추가**로 다시 정리했습니다.
- 현재 핵심 콘텐츠를 세로 반블록, SimpleOres, 계절, Terralith/Tectonic, MES, Universal Graves 중심으로 정리했습니다.
- 더 이상 현재 구성의 핵심이 아닌 요리, 확장 낚시, 가구, 추가 몹, 경제, Elytra Slot 관련 플레이 문서를 제거했습니다.
- 조합법을 별도 문서에 중복 복사하지 않고 **각 모드 페이지 안에서 바로 설명**하도록 바꿨습니다.
- `/recipes/`는 필요한 모드 페이지와 JEI 사용법으로 빠르게 이동하는 인덱스로 단순화했습니다.
- 검색에 `세로반블럭`, `광석`, `겨울`, `엔드 구조물`, `템 복구`, `디코` 같은 쉬운 표현과 영문 별칭을 추가했습니다.
- 검색의 접두어/오타 유사 검색 범위를 넓혀 정확한 모드명을 몰라도 찾기 쉽게 조정했습니다.

## 문서 원칙

현재 게임에서 바로 확인 가능한 레시피와 키 설정은 **현재 배포 클라이언트의 JEI와 조작키 화면을 최종 기준**으로 합니다. 위키는 기능을 이해하고 어디서 확인해야 하는지 빠르게 알려주는 역할을 합니다.
