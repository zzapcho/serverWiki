# 문제 해결

문제가 생기면 **증상부터 하나씩 좁히는 것**이 가장 빠릅니다. 무작정 모드를 지우면 서버와 클라이언트의 구성이 더 달라질 수 있습니다.

## 접속이 안 돼요

다음 순서대로 확인하세요.

1. Minecraft가 **26.2**인지 확인합니다.
2. 서버에서 배포한 Fabric 클라이언트 모드팩을 그대로 사용합니다.
3. 필수 콘텐츠 모드의 버전을 임의로 바꾸지 않습니다.
4. `Unknown registry`, `missing mod`, `incompatible` 같은 문구가 보이면 오류 화면을 캡처합니다.
5. Discord 인증/화이트리스트가 필요한 서버라면 인증 상태도 확인합니다.

특히 세로 반블록, SimpleOres, 계절처럼 클라이언트에도 필요한 콘텐츠 모드가 빠지거나 버전이 다르면 접속 또는 동기화 문제가 생길 수 있습니다.

## `Unknown registry` 또는 모드 동기화 오류

가장 먼저 **배포된 모드팩과 현재 `mods` 폴더를 비교**하세요. 서버에서 쓰는 모드를 임의로 하나씩 빼서 맞추려 하지 마세요.

관리자에게 보낼 때는 오류의 첫 줄만 자르지 말고, `unknown`, `registry`, `missing`, `requires`가 보이는 부분 전체를 캡처하면 좋습니다.

## 새 광물이나 레시피가 이상해요

1. JEI에서 해당 아이템을 검색합니다.
2. 클라이언트와 서버의 SimpleOres 버전이 같은 배포 세트인지 확인합니다.
3. 위키와 JEI가 다르면 **현재 게임의 JEI를 우선**합니다.
4. 특정 광물이 전혀 생성되지 않는 것 같다면 차원과 좌표, 새 청크인지 여부를 알려주세요.

## 지형이 끊겨 보여요

Terralith/Tectonic은 새로 생성되는 청크에 현재 월드 생성 규칙을 적용합니다. 오래된 청크와 새로운 청크의 경계에서는 지형 차이가 보일 수 있습니다.

반복적으로 심한 청크 생성 멈춤이나 비정상적인 절벽이 생기면 **좌표 + 스크린샷 + 새로 탐험한 지역인지**를 알려주세요.

## 계절이 안 바뀌는 것 같아요

계절은 한순간에 테마가 통째로 바뀌는 기능이 아니라 단계적으로 진행됩니다. 같은 장소의 식생 색, 날씨, 눈/얼음 변화를 시간을 두고 비교해 보세요.

클라이언트 모드팩에서 Homeostatic Seasons가 빠지지 않았는지도 확인하세요.

## 엔드 구조물이 안 보여요

MES 구조물은 이미 생성된 청크에 갑자기 나타나는 것이 아닙니다. 엔드 외곽에서 **아직 생성되지 않은 지역**을 탐험해 보세요.

## 무덤을 못 찾겠어요

먼저 다음 명령을 확인합니다.

```text
/graves
```

그래도 찾기 어렵거나 무덤 내용이 이상하다면 죽은 시각, 차원, 좌표, 주요 아이템을 관리자에게 알려주세요. 같은 자리에서 반복해서 죽거나 무덤을 여러 번 건드리기 전에 보고하는 것이 좋습니다.

## 보이스챗이 안 돼요

1. 운영체제 마이크 권한 확인
2. Simple Voice Chat 입력 장치 확인
3. 게임 내 음소거/PTT 상태 확인
4. `설정 → 조작키`에서 실제 배정 키 확인
5. 다른 프로그램에서 같은 마이크가 정상인지 비교

특정 기본키를 전제로 해결하지 않습니다. 현재 클라이언트 설정이 기준입니다.

## 그래도 해결이 안 되면

관리자에게 다음 4가지를 보내면 가장 빠릅니다.

- 무엇을 하다가 생겼는지
- 화면에 나온 정확한 오류 문구 또는 스크린샷
- 위치가 관련되면 차원과 좌표
- 재접속/재실행 후에도 같은지
