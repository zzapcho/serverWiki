# 문제 해결

문제가 생기면 **증상부터 하나씩 좁히는 것**이 가장 빠릅니다. 무작정 모드를 지우면 서버와 클라이언트 구성이 더 달라질 수 있습니다.

## 접속이 안 돼요

1. Minecraft가 **26.2**인지 확인합니다.
2. 서버에서 배포한 Fabric 클라이언트 모드팩을 그대로 사용합니다.
3. 필수 콘텐츠 모드의 버전을 임의로 바꾸지 않습니다.
4. `Unknown registry`, `missing mod`, `incompatible` 같은 문구가 보이면 오류 화면 전체를 캡처합니다.
5. Discord 인증/화이트리스트가 필요한 경우 인증 상태도 확인합니다.

특히 세로 반블록과 SimpleOres처럼 새 블록·아이템을 추가하는 모드는 클라이언트 구성 차이가 접속 문제로 이어질 수 있습니다.

## `Unknown registry` 또는 모드 동기화 오류

배포된 모드팩과 현재 `mods` 폴더를 비교하세요. 오류 첫 줄만 자르지 말고 `unknown`, `registry`, `missing`, `requires`가 보이는 부분을 함께 캡처하면 원인 파악이 빠릅니다.

## 새 광물이나 조합법이 이상해요

1. [SimpleOres 기본 생성표](/mods/simpleores#광물-생성-높이와-양)에서 차원과 Y범위를 확인합니다.
2. 클라이언트와 서버가 같은 SimpleOres 호환 버전인지 확인합니다.
3. 조합법은 JEI/REI가 아니라 [위키 조합법](/recipes/)을 기준으로 확인합니다.
4. 광물이 전혀 생성되지 않는 것 같다면 `차원 + Y좌표 + 새 청크인지`를 알려 주세요.

## FallingTree가 작동하지 않아요

1. Shift를 누르고 있지 않은지 확인합니다. 기본값에서는 웅크리면 FallingTree가 꺼집니다.
2. `/fallingtree toggle`을 한 번 입력해 자신이 기능을 꺼 둔 상태인지 확인합니다.
3. 통나무 주변에 나뭇잎이 있는 실제 나무인지 확인합니다.
4. 지나치게 큰 통나무 구조물은 기본 최대 나무 크기 100 때문에 중단될 수 있습니다.
5. 서로 다른 수종 통나무가 섞였으면 기본 설정에서 한 나무로 처리되지 않을 수 있습니다.

## 지형이 끊겨 보여요

Terralith/Tectonic은 새로 생성되는 청크에 현재 월드 생성 규칙을 적용합니다. 오래된 청크와 새 청크의 경계에서는 지형 차이가 보일 수 있습니다.

## 엔드 구조물이 안 보여요

MES 구조물은 이미 생성된 청크에 갑자기 나타나는 것이 아닙니다. 엔드 외곽에서 **아직 생성되지 않은 지역**을 충분히 탐험해 보세요.

## 무덤을 못 찾겠어요

```text
/graves
```

자신의 무덤 목록부터 확인하세요. 기본 설정에서 다른 플레이어 접근 보호는 15분, 무덤 자동 만료는 30분입니다. 무덤은 안전한 자리를 찾으면서 사망 지점 주변으로 조금 옮겨질 수도 있습니다.

## 보이스챗이 안 돼요

1. 운영체제 마이크 권한 확인
2. Simple Voice Chat 입력 장치 확인
3. 게임 내 음소거/PTT 상태 확인
4. `설정 → 조작키`에서 실제 배정 키 확인
5. 다른 프로그램에서 같은 마이크가 정상인지 비교

특정 예전 기본키를 전제로 해결하지 않습니다. 현재 클라이언트 설정이 기준입니다.

## 그래도 해결이 안 되면

관리자에게 `무엇을 하다가 생겼는지`, `오류 화면`, `관련 좌표`, `재접속/재실행 후에도 같은지`를 같이 보내 주세요.
