# 문제 해결

서버 이용 중 자주 생기는 문제를 빠르게 해결할 수 있도록 정리합니다.

## 접속이 안 돼요

- 클라이언트 버전 확인
- Fabric Loader / 필수 모드 확인
- Discord 인증 또는 화이트리스트 상태 확인
- 서버 주소 확인

## 모드 오류가 떠요

- 배포된 클라이언트 모드팩과 동일한 버전인지 확인
- 직접 추가한 모드가 충돌하지 않는지 확인
- 오류 로그의 첫 번째 `ERROR` 또는 `Caused by` 확인

## 음성채팅이 안 돼요

- `V` 설정에서 마이크 장치 확인
- 운영체제 마이크 권한 확인
- 음성채팅 연결 아이콘 확인

## 키가 겹쳐요

Minecraft의 조작 설정에서 빨간색으로 표시되는 충돌 키를 확인하고, 덜 사용하는 기능의 키를 변경하세요.

::: tip
문제가 해결되지 않으면 오류 화면이나 로그를 같이 첨부하면 훨씬 빠르게 원인을 찾을 수 있습니다.
:::
