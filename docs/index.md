## 뭐가 달라졌나요?

핵심은 **마인크래프트의 진행 방식은 최대한 그대로 두는 것**입니다. 새로운 경제나 직업, 대형 요리 시스템처럼 따로 공부해야 하는 시스템은 빼고, 바닐라에 있었어도 어색하지 않은 기능만 남겼습니다.

| 하고 싶은 것 | 달라진 점 | 바로 보기 |
| --- | --- | --- |
| 집을 더 세밀하게 짓기 | 세로 반블록 사용 가능 | [세로 반블록](/mods/vertical-slabs) |
| 광질에서 새로운 재료 찾기 | SimpleOres 광물 4종 추가 | [광물 가이드](/mods/simpleores) |
| 더 다양한 풍경 탐험하기 | Terralith + Tectonic | [지형 가이드](/mods/worldgen) |
| 계절이 바뀌는 월드 즐기기 | 봄·여름·가을·겨울 변화 | [계절 가이드](/mods/seasons) |
| 엔드에서 더 탐험하기 | MES 구조물 추가 | [엔드 구조물](/mods/end-structures) |
| 죽은 뒤 아이템 찾기 | Universal Graves | [무덤 가이드](/mods/graves) |

## 조합법은 어디서 보나요?

조합법이 필요한 기능은 **각 모드 설명 안에 바로 넣었습니다.** 전체를 빨리 찾고 싶다면 [조합법 빠른 찾기](/recipes/)를 사용하세요. 아이템 수가 많은 SimpleOres처럼 현재 설치 버전에 따라 세부 레시피가 달라질 수 있는 경우에는 **게임 안 JEI가 최종 기준**입니다.

::: tip 검색 팁
검색창에는 정확한 이름을 몰라도 됩니다. `세로반블럭`, `광석`, `겨울`, `엔드 구조물`, `템 복구`, `디코`처럼 평소 쓰는 말로 검색해도 관련 문서를 찾도록 설정되어 있습니다.
:::
