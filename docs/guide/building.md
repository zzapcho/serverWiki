# 건축

건축에서 가장 크게 달라지는 것은 **세로 반블록**과 SimpleOres의 금속/벽돌 계열 블록입니다.

## 세로 반블록

Enchanted Vertical Slabs 2.7.0은 바닐라 반블록 계열을 세워서 벽·기둥·디테일에 쓸 수 있게 합니다. 설치 JAR에는 **146개의 recipe JSON**이 있으며 제작대와 석재 절단기 레시피가 함께 들어 있습니다.

대표 제작은 재료 블록 3개를 세로로 놓아 **세로 반블록 6개**를 만드는 방식입니다.

[세로 반블록 상세 사용법 →](/mods/vertical-slabs)

## SimpleOres 건축 블록

주석·미스릴·아다만티움·오닉스에는 다음 계열이 확인됩니다.

- 재료 블록 / 원석 블록
- 금속 bars
- door
- pressure plate
- bricks / brick slab / brick stairs
- 재료별 furnace

도구·방어구까지 포함한 실제 제작 패턴은 [SimpleOres 조합법](/recipes/simpleores)에 정리했습니다.

## 실수 방지

집의 통나무를 철거할 때 FallingTree가 함께 작동할 수 있습니다. 한 블록만 부수고 싶으면 기본 설정에서 **Shift를 누른 채** 캐면 FallingTree가 잠시 비활성화됩니다.
