# 건축

건축은 거의 바닐라 그대로입니다. 추가로 알아야 할 핵심은 **세로 반블록** 하나입니다.

## 세로 반블록이 뭐예요?

바닐라 반블록은 위아래로 절반을 차지하지만, 세로 반블록은 블록의 **왼쪽 또는 오른쪽 절반**을 차지합니다. 얇은 벽, 기둥 옆면, 창틀, 벽 장식처럼 한 블록이 너무 두꺼울 때 유용합니다.

## 사용하는 순서

1. 원하는 재료의 일반 반블록과 같은 재료를 준비합니다.
2. [세로 반블록 제작법](/mods/vertical-slabs#제작법)을 확인해 제작합니다.
3. 손에 들고 원하는 면을 보며 설치합니다.
4. 같은 종류의 세로 반블록을 맞붙이면 일반 반블록을 합치는 것처럼 한 블록으로 결합할 수 있습니다.

나무 세로 반블록은 불에 탈 수 있고, 구리 세로 반블록은 바닐라 구리처럼 산화·왁스 처리가 가능합니다.
