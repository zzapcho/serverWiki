# 건축 & 가구

<p class="page-lead">바닐라 블록만으로 애매했던 디테일을 세로 반블록과 가구로 보완할 수 있습니다.</p>

<span class="status-chip is-live">사용 중</span>

## 세로 반블록

EVS(Enchanted Vertical Slabs)를 사용해 일반 반블록과 달리 **세로 방향의 반블록**을 배치할 수 있습니다.

활용 예시:

- 얇은 벽과 파티션
- 창틀/기둥 디테일
- 가구 주변 마감
- 좁은 통로의 두께 조절

제작법은 JEI에서 `vertical` 또는 블록 이름으로 검색하세요.

## 가구

Skniro's Furniture가 다양한 가구와 인테리어 블록을 추가합니다. 가구에 따라 우클릭으로 앉거나, 열거나, 기능을 사용할 수 있습니다.

::: tip 기능이 있는 가구는 재시작 후에도 확인
보관 기능이 있는 가구나 엔티티형 가구는 서버 업데이트 후 동작을 별도로 확인합니다. 문제가 있으면 바로 관리자에게 알려주세요.
:::

## 건축 팁

1. 큰 구조는 바닐라 블록으로 형태를 먼저 잡습니다.
2. 세로 반블록으로 벽/창틀 두께를 다듬습니다.
3. 마지막에 가구를 넣어 디테일을 맞춥니다.
4. 레시피는 JEI 즐겨찾기/검색을 활용하면 훨씬 빠릅니다.

## 사용 모드

- EVS (Enchanted Vertical Slabs)
- Skniro's Furniture
- JEI
