# 요리 방법 & 대표 레시피

<p class="page-lead">재료를 얻는 단계부터 도마·냄비·프라이팬 사용과 완성 음식 선택까지 한 흐름으로 연결합니다.</p>

## 먼저 기억할 것

| 하고 싶은 일 | 가장 빠른 확인법 |
|---|---|
| 재료의 모든 사용처 보기 | 인벤토리에서 재료에 마우스를 올리고 <kbd>U</kbd> |
| 음식 만드는 법 보기 | 음식에 마우스를 올리고 <kbd>R</kbd> |
| 조리 기구 확인 | 레시피 화면 위쪽의 `Cooking`, `Cutting` 등 유형 확인 |
| 다른 재료로 대체 가능한지 보기 | 재료 칸이 순환 표시되는지 확인 |
| 현재 서버의 정확한 수량 확인 | 위키보다 현재 JEI 레시피를 최종 기준으로 사용 |

이 버전의 공식 데이터에는 일반 제작과 호환 레시피를 포함해 수백 개의 항목이 있습니다. 위키는 모든 칸을 복제하기보다 **조리 방법과 대표 조합**을 설명하고, 정확한 출력 수량·태그 대체 재료는 JEI가 담당합니다.

## 재료를 얻는 순서

1. 토마토·양배추·양파·벼 같은 야생 작물을 탐험 중 찾습니다.
2. 씨앗이나 작물을 거점으로 가져와 밭을 만듭니다.
3. 벼는 일반 밭이 아니라 **얕은 물에 심는 작물**이므로 배치 안내를 확인합니다.
4. 칼과 도마로 고기·채소·생선·빵을 손질합니다.
5. 손질한 재료를 제작대, 냄비, 프라이팬 등 JEI가 표시하는 기구에 넣습니다.

::: tip 처음 시작할 때
철을 많이 쓰기 전에는 부싯돌 칼과 도마부터 확인하고, 농장에는 토마토·양배추·양파·쌀을 조금씩 모두 심어 두면 대부분의 대표 음식으로 확장하기 쉽습니다.
:::

## 도마: 올리고, 도구로 자르고, 회수

1. 도마를 바닥이나 작업대 높이에 설치합니다.
2. 손질할 재료를 손에 들고 도마를 우클릭해 올립니다.
3. 재료의 <kbd>R</kbd> 화면에서 `Cutting` 레시피와 요구 도구를 봅니다.
4. 칼 또는 표시된 도구를 들고 도마의 재료에 상호작용합니다.
5. 잘린 재료와 부산물을 회수합니다.

도마에는 고기·생선 손질뿐 아니라 양배추 잎, 파이 조각, 나무껍질, 짚 등으로 이어지는 레시피도 있습니다. “칼로 자르면 될 것 같다”는 추측보다 JEI에 `Cutting` 유형이 실제로 있는지를 먼저 확인하세요.

## 요리 냄비: 여러 재료를 한 번에 조리

1. 스토브처럼 사용할 수 있는 열원을 준비합니다.
2. 그 위에 Cooking Pot을 놓고 우클릭해 GUI를 엽니다.
3. 만들 음식에 <kbd>R</kbd>을 눌러 `Cooking` 레시피를 선택합니다.
4. 표시된 재료를 넣고 진행 표시가 끝날 때까지 기다립니다.
5. 출력 칸이 그릇이나 병을 요구하면 해당 용기를 준비해 완성품을 꺼냅니다.

### 냄비 대표 레시피

| 결과 | 핵심 재료 | 활용 |
|---|---|---|
| 비프 스튜 | 생소고기 + 당근 + 감자 | 초반 고기·밭작물 식사 |
| 치킨 수프 | 생닭고기 + 당근 + 잎채소 + 채소 | 여러 밭작물 소비 |
| 생선 스튜 | 안전한 생선 + 토마토소스 + 양파 | 낚시와 농사 연결 |
| 볶음밥 | 쌀 + 달걀 + 당근 + 양파 | 반복 생산하기 쉬운 식사 |
| 만두 | 반죽 + 양배추 + 양파 + 고기 또는 버섯 | 재료 선택 폭이 넓음 |
| 미트볼 파스타 | 다진 소고기 + 파스타 + 토마토소스 | 도마 가공과 소스 조리 연결 |
| 라따뚜이 | 토마토 + 양파 + 비트 + 다른 채소 | 채소 위주 식사 |
| 야채 수프 | 당근 + 감자 + 비트 + 잎채소 | 바닐라 작물 활용 |
| 속을 채운 호박 | 쌀 + 양파 + 버섯 + 감자 + 베리 + 채소 | 재료가 많이 드는 공유 음식 |
| 사과주 | 사과 2 + 설탕 | 병을 쓰는 음료 계열 |

`#c:crops/...`처럼 묶음 태그를 쓰는 재료는 특정 아이템 하나로 고정되지 않을 수 있습니다. 실제 선택지는 JEI에서 재료 칸에 마우스를 올려 확인하세요.

## 프라이팬: 손에 재료를 들고 직접 굽기

프라이팬은 냄비 GUI와 사용법이 다릅니다. 팬을 설치하거나 손에 든 상태에서 안내 문구와 JEI의 `Cooking`/가열 레시피를 확인하고, **다른 손에 재료를 준비하는 흐름**이 사용됩니다.

- 반응이 없으면 재료가 프라이팬 조리 대상인지 확인합니다.
- 물에 잠긴 팬은 조리되지 않을 수 있습니다.
- 결과가 바닥에 떨어질 수 있으므로 팬 주변에 회수 공간을 둡니다.
- 같은 재료도 화로·훈연기·캠프파이어·팬 레시피가 서로 다를 수 있습니다.

## 큰 접시 음식과 파이

로스트 치킨, 셰퍼드 파이, 속을 채운 호박, 파이류처럼 블록 형태로 놓고 나누어 먹는 음식이 있습니다.

1. JEI에서 완성 블록의 레시피를 확인합니다.
2. 식탁처럼 접근 가능한 곳에 설치합니다.
3. 필요한 그릇/도구가 있는지 툴팁과 상호작용을 확인합니다.
4. 여러 명이 먹을 때 남은 횟수와 블록 상태를 확인합니다.

## 농사·낚시·경제 연결

- 낚은 안전한 생선은 생선 스튜, 생선 요리 또는 Gone Fishing 가공 음식의 재료가 될 수 있습니다.
- 토마토소스와 파스타처럼 중간 재료를 미리 생산하면 주문 대응이 빨라집니다.
- 서버 매입은 일일 판매 한도가 있으므로 완제품을 무작정 쌓기보다 `/orders`와 플레이어 상점을 함께 비교합니다.
- 희귀 낚시 재료나 탐험 재료가 들어간 음식은 반복 매입보다 플레이어 거래 가치가 더 클 수 있습니다.

## 안 될 때

| 증상 | 확인 순서 |
|---|---|
| 도마에 재료가 안 올라감 | 손에 든 아이템 확인 → 클릭 면 확인 → `Cutting` 레시피 존재 확인 |
| 도구를 써도 안 잘림 | JEI가 요구하는 칼/도구인지 확인 |
| 냄비가 진행되지 않음 | 열원 → 재료 종류/개수 → 출력 용기 → 출력 칸 여유 순으로 확인 |
| 팬이 반응하지 않음 | 다른 손의 재료 → 물에 잠겼는지 → 해당 가열 레시피 존재 여부 확인 |
| 문서와 재료가 다름 | 현재 JEI와 서버 배포 버전을 최종 기준으로 사용 |
