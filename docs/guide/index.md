## 문서 표기

- <span class="status-chip is-live">사용 중</span> 현재 서버에서 실제로 사용하는 기능.
- <span class="status-chip is-beta">검증 중</span> 동작하지만 특정 조건/경고를 더 테스트해야 하는 기능.
- <span class="status-chip is-plan">계획</span> 아직 서버에 구현되지 않은 기능.

## 이 위키가 일부 수치를 고정하지 않는 이유

키 바인딩, 모드 레시피, 서버 상점 가격처럼 **현재 배포본에서 즉시 확인 가능한 데이터**는 업데이트 때 쉽게 달라집니다. 이런 값은 JEI, Minecraft 키 설정, 실제 상점 UI를 최종 기준으로 두고 위키에는 “어디서 어떻게 확인하는지”까지 적습니다.

::: tip 찾고 싶은 행동을 검색하세요
`겉날개`, `죽음`, `돈`, `낚시`, `도마`, `Voice`, `가구`처럼 기능 이름만 입력해도 관련 문서가 나오도록 구성합니다.
:::
