# 서버 가이드

이 서버는 **바닐라 마인크래프트를 크게 바꾸지 않는 Vanilla+ 서버**입니다. 처음 보는 모드가 많아 보여도 실제로 알아야 할 것은 많지 않습니다.

## 가장 먼저 볼 것

처음이라면 [바닐라와 달라진 점](/guide/vanilla-differences)만 읽어도 충분합니다. 그다음 실제로 필요한 순간에 아래 문서를 열면 됩니다.

| 상황 | 읽을 문서 |
| --- | --- |
| 세로 반블록으로 건축하고 싶다 | [건축](/guide/building) |
| 새 광물이나 지형이 궁금하다 | [탐험 & 월드](/guide/exploration) |
| 죽었는데 아이템이 어디 갔는지 모르겠다 | [생존 & 죽음](/guide/survival) |
| 특정 모드 사용법이 궁금하다 | [모드 한눈에 보기](/mods/) |
| 만드는 법이 궁금하다 | [조합법 빠른 찾기](/recipes/) |

## 기본 원칙

바닐라의 채굴, 제작, 전투, 네더 진행, 엔드 진입 같은 큰 흐름은 그대로입니다. 추가된 기능은 대부분 **기존 플레이 옆에 선택지가 하나 더 생기는 방식**입니다.

- 건축: 세로 방향 반블록이 추가됩니다.
- 광질: 새로운 광석과 재료가 추가됩니다.
- 월드: 오버월드 지형이 더 다양하고 크게 생성됩니다.
- 계절: 시간이 지나며 환경의 분위기가 달라집니다.
- 엔드: 바닐라 느낌의 구조물을 더 만날 수 있습니다.
- 죽음: 아이템이 무덤에 보관됩니다.

모드 이름을 외울 필요는 없습니다. **무엇을 하고 싶은지**로 문서를 찾으면 됩니다.
