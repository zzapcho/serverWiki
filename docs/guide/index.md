# 서버 가이드

ZZAPCHO SERVER에서 **바닐라와 달라진 점**, 추가 콘텐츠, 서버 규칙과 플레이 방식 등을 정리하는 공간입니다.

## 이 가이드에 들어갈 내용

- 농사와 요리
- 낚시와 추가 어종
- 가구와 건축 기능
- 월드 지형과 구조물
- 죽음, 무덤, 인벤세이브권
- 겉날개 + 갑옷 동시 착용
- 경제와 거래
- Discord / 음성채팅

## 문서 작성 원칙

모드 이름보다 **플레이어가 실제로 무엇을 할 수 있는지**를 먼저 설명합니다.

예를 들어:

> `Farmer's Delight`가 설치되어 있습니다.

보다는:

> 새로운 요리 도구와 음식이 추가됩니다. 어떤 음식이 있고 어떻게 만드는지는 아래에서 확인하세요.

처럼 설명합니다.

::: tip
모드 이름과 버전은 각 페이지 아래쪽에 참고 정보로 따로 표시할 예정입니다.
:::
