## 읽는 순서

처음이라면 **바닐라와 달라진 점 → 생존 & 죽음 → 조작법 → 경제** 정도만 먼저 보면 충분합니다. 나머지는 플레이하다 필요할 때 검색해서 찾으면 됩니다.
