# 탐험 & 월드

<p class="page-lead">“멀리 가는 것” 자체가 콘텐츠입니다. 지형, 구조물, 추가 몹과 희귀 전리품을 지도에 기록하면서 탐험 범위를 넓힙니다.</p>

<span class="status-chip is-live">사용 중</span>

## 왜 월드가 다르게 보이나요?

- **Terralith**: 바이옴/지역 분위기 다양화.
- **Tectonic**: 산맥, 계곡, 절벽 등 큰 지형 형태.
- **Dungeons and Taverns**: 탐험 구조물과 던전.
- **Friends&Foes**: 새로운 몹/구조/전리품 요소.

이 구성은 새로운 광석/기계 UI를 잔뜩 넣는 것보다 **바닐라 재료와 탐험 감각을 확장**하는 방향입니다.

## 새 청크의 의미

월드 생성은 청크가 처음 만들어질 때 결정됩니다. 그래서 업데이트 뒤:

- 이미 지도에 저장된 곳은 그대로일 수 있음.
- 새 지형을 보려면 기존 탐험 경계 밖으로 가야 할 수 있음.
- 월드 생성 모드 교체/업데이트는 경계가 어색해질 수 있어 백업 후 테스트가 필요.

## JourneyMap 사용

<kbd>J</kbd>로 전체 지도를 열어:

- 거점.
- 마을/던전.
- 희귀 바이옴.
- 네더 포털 출구.
- 친구의 주요 건축물.

같은 위치를 웨이포인트로 남기면 좋습니다.

웨이포인트 기본키는 배포 팩/개인 설정에 따라 충돌할 수 있으므로 현재 **조작 설정의 JourneyMap 항목**을 최종 기준으로 확인하세요.

## Friends&Foes를 만났을 때

처음 보는 생물은 바로 공격하기 전에:

1. 적대 여부 확인.
2. 손에 든 먹이/관련 아이템에 반응하는지 관찰.
3. JEI에서 몹 이름/전리품 검색.
4. 구조물 주변이라면 스폰/전리품 연결 여부 확인.

→ [Friends&Foes 상세](/mods/friends-and-foes)

## 탐험 준비 체크

- 음식.
- 블록/횃불.
- 침대 또는 귀환 계획.
- 장비 내구도.
- 여분의 상자/셜커가 있다면 수납.
- 겉날개 사용 시 전용 슬롯 장착 확인.
- 죽었을 때 `/graves`로 확인하는 법 숙지.
