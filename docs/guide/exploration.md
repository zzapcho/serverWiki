# 탐험 & 월드

<p class="page-lead">“멀리 가는 것” 자체가 콘텐츠입니다. 지형, 구조물, 추가 몹과 희귀 전리품을 지도에 기록하면서 탐험 범위를 넓힙니다.</p>

<span class="status-chip is-live">사용 중</span>

## 왜 월드가 다르게 보이나요?

- **Terralith**: 바이옴/지역 분위기 다양화.
- **Tectonic**: 산맥, 계곡, 절벽 등 큰 지형 형태.
- **Dungeons and Taverns**: 탐험 구조물과 던전.
- **Friends&Foes**: 새로운 몹/구조/전리품 요소.

이 구성은 새로운 광석/기계 UI를 잔뜩 넣는 것보다 **바닐라 재료와 탐험 감각을 확장**하는 방향입니다.

## 이 월드에서 할 수 있는 것

| 목표 | 무엇을 찾나 | 다음 행동 |
|---|---|---|
| 풍경 거점 | 큰 산맥, 계곡, 해안, 특색 있는 Terralith 지역 | 접근로·고도·주변 자원을 확인하고 웨이포인트 저장 |
| 구조물 원정 | Dungeons and Taverns의 여관·폐허·던전 계열 | 입구 안전 확보 → 적대 몹/함정 확인 → 전리품 회수 |
| 생물 관찰 | Friends&Foes가 확장한 몹과 관련 구조 | 공격 전 반응과 상호작용 아이템 확인 |
| 자원 교역 | 멀리 떨어진 바이옴·구조물 자원 | 귀환 뒤 `/orders`와 플레이어 상점 수요 확인 |
| 탐험 지도 | 포털, 거점, 희귀 지형, 던전 | JourneyMap 웨이포인트 이름과 차원을 명확히 기록 |
| 건축 후보 조사 | 평지뿐 아니라 절벽·계곡·능선 | 큰 평탄화 전에 지형을 살리는 설계 검토 |

이 조합 자체가 별도 기계 화면이나 새 차원 입장법을 추가하는 것은 아닙니다. 오버월드의 생성 결과와 탐험 밀도를 바꾸며, 실제 제작법은 발견한 전리품에 <kbd>R</kbd>/<kbd>U</kbd>를 눌러 확인합니다.

## 새 청크의 의미

월드 생성은 청크가 처음 만들어질 때 결정됩니다. 그래서 업데이트 뒤:

- 이미 지도에 저장된 곳은 그대로일 수 있음.
- 새 지형을 보려면 기존 탐험 경계 밖으로 가야 할 수 있음.
- 월드 생성 모드 교체/업데이트는 경계가 어색해질 수 있어 백업 후 테스트가 필요.

## JourneyMap 사용

<kbd>J</kbd>로 전체 지도를 열어:

- 거점.
- 마을/던전.
- 희귀 바이옴.
- 네더 포털 출구.
- 친구의 주요 건축물.

같은 위치를 웨이포인트로 남기면 좋습니다.

웨이포인트 기본키는 배포 팩/개인 설정에 따라 충돌할 수 있으므로 현재 **조작 설정의 JourneyMap 항목**을 최종 기준으로 확인하세요.

## Friends&Foes를 만났을 때

처음 보는 생물은 바로 공격하기 전에:

1. 적대 여부 확인.
2. 손에 든 먹이/관련 아이템에 반응하는지 관찰.
3. JEI에서 몹 이름/전리품 검색.
4. 구조물 주변이라면 스폰/전리품 연결 여부 확인.

→ [Friends&Foes 상세](/mods/friends-and-foes)

## 탐험 준비 체크

- 음식.
- 블록/횃불.
- 침대 또는 귀환 계획.
- 장비 내구도.
- 여분의 상자/셜커가 있다면 수납.
- 겉날개 사용 시 전용 슬롯 장착 확인.
- 죽었을 때 `/graves`로 확인하는 법 숙지.

## 구조물에 들어갈 때

1. 입구 바깥에 임시 상자나 귀환 웨이포인트를 둡니다.
2. 아래층/막힌 방에 바로 뛰어들지 말고 퇴로부터 밝힙니다.
3. 상자는 주변 함정과 적대 몹을 정리한 뒤 엽니다.
4. 처음 보는 전리품은 버리기 전에 JEI <kbd>U</kbd>로 사용처를 봅니다.
5. 구조물이 잘렸거나 겹쳐 있으면 새 청크인지 확인하고 좌표와 스크린샷을 남깁니다.
