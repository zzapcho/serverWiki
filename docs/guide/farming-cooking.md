## 새 작물을 얻었을 때

아이템에 <kbd>U</kbd>를 눌러 **어디에 쓰이는지** 먼저 봅니다. 한 재료가 여러 음식에 들어간다면:

- 내가 자주 먹을 음식.
- 친구가 주문한 음식.
- 서버 판매가/재료 원가가 괜찮은 음식.
- 희귀 재료가 필요한 고급 음식.

중에서 목적을 정한 뒤 제작하는 편이 효율적입니다.

## 도마

도마는 단순 제작대가 아니라 **재료를 월드 블록 위에 올리고 도구로 손질**하는 흐름입니다.

1. 도마 설치.
2. 재료 올리기.
3. JEI에서 해당 Cutting 레시피 확인.
4. Knife 등 요구 도구로 상호작용.
5. 결과물/부산물 회수.

## 요리 냄비

여러 재료를 동시에 처리하는 요리에서 사용합니다.

1. 적절한 열원 준비.
2. Cooking Pot 설치.
3. 음식의 <kbd>R</kbd> 레시피 유형 확인.
4. 재료 투입.
5. 조리 진행 확인.
6. 필요하면 그릇/병 같은 출력 용기 준비.

## 스토브와 프라이팬

스토브는 열원, 프라이팬은 직접 가열 조리의 역할을 맡습니다. 모든 음식이 냄비를 쓰는 것은 아니므로 **음식 이름 → R → 레시피 유형** 순으로 확인하면 잘못된 조리 블록에 재료를 넣는 일을 줄일 수 있습니다.

## 경제 팁

- 작물 원재료는 안정적인 반복 생산이 장점.
- 완제품은 가공 시간과 재료 수가 추가되므로 서버 매입가만 보고 만들기보다 플레이어 주문을 같이 확인.
- 서버에서 살 수 있는 재료를 다시 조합해 되파는 차익은 가격표에서 제한하는 방향.
- 희귀 요리는 서버 상점보다 플레이어 거래가 더 가치 있을 수 있음.

## 자동화에 대한 기준

이 서버의 생활 콘텐츠는 완전 자동 공장보다 **직접 플레이와 거래가 남는 정도**가 목표입니다. 대규모 자동 농장을 만들기 전에는 서버 규칙과 성능 영향을 확인하세요.
