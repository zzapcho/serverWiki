# 농사 & 요리

<p class="page-lead">농사는 음식 확보뿐 아니라 요리, 거래와 경제로 이어지는 하나의 플레이 루프가 됩니다.</p>

<span class="status-chip is-live">사용 중</span>

## 뭐가 달라지나요?

Farmer's Delight Refabricated를 중심으로 바닐라 음식보다 다양한 **식재료, 조리 도구, 음식 레시피**가 추가됩니다.

기본 흐름은 간단합니다.

  <div class="flow-card"><span class="flow-number">02</span><strong>레시피 확인</strong><p>JEI에서 만들고 싶은 음식의 레시피와 필요한 도구를 확인합니다.</p></div>
  <div class="flow-card"><span class="flow-number">03</span><strong>요리 & 활용</strong><p>직접 먹거나, 다른 플레이어에게 판매하거나, 생활 플레이에 활용합니다.</p></div>
</div>

## 레시피 찾는 법

인벤토리에서 JEI 검색창에 음식이나 재료 이름을 검색하세요.

- 아이템 위에서 <kbd>R</kbd>: 레시피 확인(기본 설정 기준)
- 아이템 위에서 <kbd>U</kbd>: 해당 아이템이 어디에 쓰이는지 확인(기본 설정 기준)
- 키가 다르면 Minecraft 조작 설정에서 JEI 키를 확인하세요.

## 경제와 연결

농사/요리는 서버 경제에서 **지속적으로 생산 가능한 생활형 수입원**으로 사용할 예정입니다. 단, 재료를 서버 상점에서 사서 완제품으로 되파는 식의 무한 차익이 생기지 않도록 가격을 조정합니다.

::: info 가격은 아직 밸런싱 중입니다
어떤 작물/음식을 서버가 얼마에 사는지는 경제 가격표가 확정된 뒤 위키에 공개합니다.
:::
