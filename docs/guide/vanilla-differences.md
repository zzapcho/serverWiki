## 플레이 루프가 어떻게 달라지나요?

### 생활

```text
작물/재료 수집
  → 도마/조리도구 가공
  → 음식 제작
  → 직접 사용 / 플레이어 거래 / 서버 판매
```

농사가 단순 빵 공급이 아니라 경제 활동이 되고, 낚시도 수집/음식/희귀 전리품 시장과 연결됩니다.

### 탐험

```text
새 청크 탐험
  → 새로운 지형/구조물/몹 발견
  → 웨이포인트 저장
  → 전리품·재료를 거점/거래로 가져오기
```

월드 생성 모드는 이미 생성된 청크를 즉시 다시 만드는 것이 아니라 새로 만들어지는 지역에 적용됩니다.

### 생존

죽으면 아이템이 일반적으로 Universal Graves 무덤에 들어갑니다. `/graves`로 자신의 무덤 목록을 확인할 수 있습니다. 또한 겉날개 전용 슬롯이 있어 흉갑을 유지하면서 Elytra를 사용할 수 있습니다.

### 커뮤니티

서버 입장 전 Discord 인증을 하고, 서버 안 일반 채팅은 Discord와 연결됩니다. 실시간 대화는 Simple Voice Chat을 사용합니다.

## “모드팩 서버”와 다른 느낌

이 서버는 거대한 기술 트리나 기계 자동화가 핵심인 kitchen-sink 구성보다 **Vanilla++**에 가깝습니다. 바닐라의 채광·건축·탐험을 유지하면서 “할 거리와 편의”를 넓히는 쪽입니다.
