# 바닐라와 달라진 점

<p class="page-lead">“그래서 이 서버는 바닐라랑 뭐가 다른데?”를 한 페이지에서 확인할 수 있도록 핵심만 묶었습니다.</p>

## 한눈에 보기

| 분야 | 달라지는 점 | 주요 구현 |
|---|---|---|
| 농사/요리 | 식재료와 조리 콘텐츠가 확장됨 | Farmer's Delight Refabricated |
| 낚시 | 추가 어종과 보상이 생김 | Go Fish |
| 건축 | 세로 반블록과 가구 사용 가능 | EVS, Skniro's Furniture |
| 월드 | 지형과 구조물이 크게 다양해짐 | Terralith, Tectonic, Dungeons & Taverns |
| 생물 | 바닐라풍 추가 생물 콘텐츠 | Friends&Foes |
| 죽음 | 아이템이 무덤에 보관됨 | Universal Graves |
| 장비 | 흉갑과 겉날개 동시 착용 가능 | Elytra Slot |
| 경제 | 잔액, 상점, 거래, 일일 보상 | EconomyCraft |
| 편의 | 레시피 검색, 지도, HUD 등 | JEI, JourneyMap 등 클라이언트 모드 |
| 커뮤니티 | 근거리 보이스 + Discord 채팅 연동 | Simple Voice Chat, Discord Integration |

## 생활 플레이

단순히 광질하고 장비만 맞추는 것보다 **농사 → 요리 → 판매**, **낚시 → 거래**, **건축 → 가구 배치**처럼 생활형 플레이가 훨씬 넓어졌습니다.

- [농사 & 요리](/guide/farming-cooking)
- [낚시](/guide/fishing)
- [건축 & 가구](/guide/building)

## 월드와 탐험

기존 바닐라와 비교하면 산맥, 계곡, 생물군계의 분위기와 구조물 배치가 훨씬 다양합니다. 새로운 지역을 찾는 과정 자체가 서버 플레이의 큰 비중을 차지합니다.

자세한 내용은 [탐험 & 월드](/guide/exploration)에서 확인하세요.

## 죽음과 장비

죽으면 아이템이 바닥에 흩어지는 대신 **무덤 시스템**이 사용됩니다. 또한 겉날개 전용 슬롯이 있어 흉갑과 겉날개를 동시에 착용할 수 있습니다.

향후 서버 전용 **인벤세이브권**도 경제 시스템과 연결해 추가할 예정입니다.

## 경제

기본 잔액, 일일 보상, 서버 상점, 플레이어 상점과 주문 기능이 있습니다. 돈은 단순 장식이 아니라 거래와 편의 기능에 실제로 쓰이도록 설계합니다.

→ [경제 시스템 자세히 보기](/economy/)
