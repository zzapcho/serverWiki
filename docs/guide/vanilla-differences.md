# 바닐라와 달라진 점

이 페이지는 서버에 처음 온 사람이 **“그래서 바닐라랑 뭐가 다른데?”**를 가장 빠르게 확인하는 곳입니다.

## 생활

- 농사와 요리 콘텐츠가 확장됩니다.
- 낚시에서 추가 보상과 어종을 만날 수 있습니다.
- 가구와 추가 건축 요소를 사용할 수 있습니다.

## 탐험

- 지형 생성이 더 다양해집니다.
- 새로운 구조물과 탐험 포인트가 추가됩니다.

## 생존

- 사망 시 무덤 시스템을 사용합니다.
- 추후 인벤세이브권 같은 서버 전용 아이템이 추가될 예정입니다.
- 겉날개와 흉갑을 함께 착용할 수 있습니다.

## 편의 기능

- 레시피 검색
- 월드 지도
- 음성채팅
- 서버 ↔ Discord 채팅 연동
- 각종 HUD와 클라이언트 편의 기능

## 경제

서버 화폐, 상점, 거래, 수표 등은 별도 [경제 가이드](/economy/)에서 설명합니다.

::: warning
이 문서는 현재 테스트용 개요입니다. 실제 오픈 전에는 '추가됨 / 변경됨 / 삭제됨'을 기준으로 더 정확하게 정리할 예정입니다.
:::
