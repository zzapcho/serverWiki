# 물고기 확률·조건 & 낚싯대 도감

<p class="page-lead">어디서 어떤 물고기를 노려야 하는지, 확률은 어떻게 읽는지, 낚싯대와 루어는 어떻게 얻는지 정리합니다.</p>

<span class="status-chip is-beta">차원 전리품 검증 중</span>

## 확률을 읽는 법

오버월드에서 행운 0, 열린 물 조건을 만족했을 때 최상위 기본 가중치는 다음과 같습니다.

| 분류 | 가중치 | 기본 근사 확률 |
|---|---:|---:|
| 물고기 풀 | 85 | 80.95% |
| 쓰레기 | 10 | 9.52% |
| 보물 | 5 | 4.76% |
| Gone Fishing 상자 | 5 | 4.76% |

그다음 물고기 풀 안에서 바이옴·날씨·높이·보름달 조건에 맞는 추가 어종이 바닐라 물고기 가중치 100에 더해집니다. 따라서 아래의 “전체 근사”는 **해당 조건만 추가되고 다른 조건은 겹치지 않는 상황**의 계산값입니다.

::: warning 고정 확률이 아닌 이유
행운/바다의 행운, 열린 물 판정, 여러 날씨·바이옴 조건의 동시 성립, 서버 데이터팩 변경에 따라 실제 확률이 달라집니다. 정확한 운영값을 검증할 때는 같은 조건으로 충분한 횟수를 기록하세요.
:::

## 네더 의도 데이터

네더 최상위 가중치는 물고기 80, 쓰레기 10, 보물 5, 상자 5입니다. 물고기 풀의 의도 데이터는 다음과 같습니다.

| 어종 | 기본 가중치 | 추가 조건 |
|---|---:|---|
| Smokey Salmon | 30 | 네더 공통 |
| Magma Cod | 30 | 네더 공통 |
| Bonefish | 15 | 네더 공통 |
| Obsidian Halibut | 15 | 네더 공통 |
| Basalt Bass | 15 | 네더 공통 |
| Spikerfish | 15 | 네더 공통 |
| Gilded Blackstone Carp | 15 | 현무암 삼각주 |
| Blackstone Trout | 15 | 현무암 삼각주 |
| Soul Salmon | 15 | 영혼 모래 골짜기 |

특수 바이옴이 아닌 곳의 물고기 풀 기준으로 앞의 두 어종은 각 25%, 나머지는 각 12.5%입니다. 단, 현재 서버에는 네더 loot table 파싱 경고가 있으므로 이 표는 **모드가 의도한 데이터**이며 실서버 드롭 보장을 뜻하지 않습니다.

## 상자 종류와 조건

열린 물에서 Gone Fishing 상자가 선택되면 기본 Wooden 4, Iron 3, Golden 2, Diamond 1 가중치에 조건별 상자가 추가됩니다.

| 상자 | 추가 가중치 | 조건 |
|---|---:|---|
| Astral Crate | 4 | 보름달이며 바깥이 어두움 |
| Supply Crate | 2 | 평원·숲·강 계열 |
| Soul Crate | 3 | 네더 |
| Frosted Crate | 4 | 얼음 계열 바이옴 |
| Slimey Crate | 4 | 늪 계열 바이옴 |
| Gilded Blackstone Crate | 4 | 현무암 삼각주 |

조건 상자가 추가되면 기본 네 상자의 상대 확률도 함께 달라집니다.

## 물고기를 얻은 뒤

- Icicle Fish는 그대로 먹을 때 위험한 효과가 있으므로 툴팁을 확인합니다.
- Slimefish는 슬라임볼, Seaweed Eel은 해초, Blizzard Bass는 얼음 계열, Obsidian Halibut은 흑요석, Bonefish는 뼛가루 등으로 가공되는 레시피가 있습니다.
- Smokey Salmon과 Magma Cod처럼 먹었을 때 상태 효과를 주는 어종도 있습니다.
- 생선에 <kbd>U</kbd>를 눌러 음식·재료·장비 제작 사용처를 먼저 확인하세요.

## 표본을 제대로 기록하는 법

확률 오류를 제보할 때는 `차원 / 바이옴 / Y 높이 / 날씨 / 달 위상 / 낚싯대·마법 / 열린 물 여부 / 총 시도 / 결과별 개수`를 함께 남깁니다. 10~20회 결과만으로 희귀 전리품이 고장 났다고 단정하기는 어렵습니다.
