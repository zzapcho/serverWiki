# 가구·건축 카탈로그

<p class="page-lead">방별로 어떤 가구를 찾고, 어떻게 배치하고, 설치 뒤 무엇을 확인해야 하는지 쉽게 정리합니다.</p>

## 실제로 무엇이 있나요?

현재 서버에는 목재·염색·형태 변형을 포함해 2천 개가 넘는 가구 제작 항목이 있습니다. 모든 변형 이름을 긴 표로 복제하기보다 JEI에서 아래 카테고리를 검색하는 편이 빠르고 정확합니다.

| 공간 | JEI에서 찾아볼 종류 | 배치 포인트 |
|---|---|---|
| 거실 | Sofa, Coffee Table, End Table, TV, TV Stand, Bookshelf | 소파 앞 동선과 TV 클릭 면 확보 |
| 주방 | Kitchen Counter, Counter Drawer, Kitchen Cabinet, Wall Cabinet, Sink, Oven, Fridge, Plate | 상부장 아래 여유와 문 열림 방향 확인 |
| 침실 | Bed, Bedside Cabinet, Desk Cabinet, Desk Lamp | 침대 스폰 기능과 장식 침대를 혼동하지 않기 |
| 식당 | Table, Chair, Coffee Chair, Glass Table, Plate | 의자 뒤 이동 공간 확보 |
| 서재 | Book Desk, Bookshelf, Desk Cabinet, Desk Lamp | 책상 폭과 수납 클릭 면 확인 |
| 욕실/세면 공간 | Sink, Divider, Cabinet | 물 장식이 기능성인지 설치 후 확인 |
| 출입구 | Glass Sliding Door, Grid Sliding Door, Paper Sliding Door | 문이 움직일 방향과 옆 블록 간섭 확인 |
| 외벽/창호 | Window, Window Style 2, Divider | 벽 두께와 목재/판자 테마 맞추기 |
| 장식 | Cushion, Draw, Teddy Bear, Ceiling Lamp | 염색·캐릭터·목재 변형을 이름으로 좁혀 검색 |

## 변형이 많은 카테고리

- 침대: 목재/판자와 염색 조합이 매우 많습니다.
- 슬라이딩 도어: 유리·격자·종이 스타일과 목재/색상 변형이 있습니다.
- Draw: Allay, Axolotl, Bee, Creeper 등 무늬와 목재 변형이 있습니다.
- Cushion: 16색과 여러 목재 변형이 있습니다.
- 주방 세트: 카운터·서랍·싱크·오븐·냉장고·벽장·캐비닛을 같은 재료로 맞출 수 있습니다.
- 창문: 판자/통나무 계열과 두 가지 스타일을 비교할 수 있습니다.

## JEI에서 빠르게 고르는 법

1. 먼저 `sofa`, `cabinet`, `window`처럼 종류를 검색합니다.
2. 원하는 목재 이름을 함께 입력해 후보를 줄입니다.
3. 색이 필요한 항목은 색 이름까지 추가합니다.
4. 후보에 <kbd>R</kbd>을 눌러 재료와 출력 수량을 비교합니다.
5. 한 개만 시험 제작해 크기·방향·우클릭 반응을 본 뒤 묶음 제작합니다.

한글 이름이 검색되지 않으면 영문 이름의 일부를 사용하세요. 모드 이름 필터가 지원되는 현재 JEI 구성에서는 Skniro 항목만 좁혀 보는 것도 유용하지만, 검색 문법은 화면의 JEI 도움말을 최종 기준으로 합니다.

## Vertical Slabs와 같이 쓰기

세로 반블록은 가구가 아니라 건물의 두께를 다듬는 재료입니다.

- 주방 상판 옆 마감.
- 창틀과 문틀의 반칸 깊이.
- 소파 뒤 낮은 파티션.
- 책장 옆 얇은 기둥.
- 복도와 방 사이 공간 분리.

제작대에서 같은 재료를 세로 한 줄로 놓는 패턴이 기본입니다. 지원 블록과 출력 수량은 재료 아이템에 <kbd>R</kbd>을 눌러 확인하세요.

## 방 하나를 완성하는 순서

1. 바닐라 블록으로 바닥·벽·천장과 출입구를 완성합니다.
2. 가장 큰 가구부터 임시 배치해 통로 폭을 확인합니다.
3. Vertical Slabs로 파티션·창틀·벽 두께를 보정합니다.
4. 수납·문·조명처럼 클릭할 가구를 설치하고 앞 공간을 비웁니다.
5. 쿠션·그림 서랍·접시·인형 같은 작은 장식을 마지막에 넣습니다.
6. 낮과 밤, 밝은/어두운 화면에서 색 대비와 조명을 확인합니다.

## 상호작용과 저장 안정성

가구를 설치한 뒤 우클릭해 수납 UI, 개폐, 조명/상태 변화가 있는지 확인합니다. 이름이 기능처럼 보여도 순수 장식일 수 있으므로 기능을 단정하지 마세요.

현재 서버에서 data fixer 관련 경고가 관찰되었으므로 중요한 수납형/상태형 가구는 다음 순서로 검증합니다.

1. 가구 하나에 가치 낮은 시험 아이템을 넣거나 상태를 바꿉니다.
2. 좌표와 가구 이름을 기록합니다.
3. 정상적인 서버 재시작 뒤 블록·방향·내용·상태를 확인합니다.
4. 검증 전에는 유일한 희귀품의 단독 보관소로 사용하지 않습니다.
