# 생존 & 죽음

<p class="page-lead">죽음 아이템 처리와 장비 슬롯이 바닐라와 다릅니다. 서버에서 가장 먼저 알아둘 규칙입니다.</p>

## 죽으면 어떻게 되나요?

<span class="status-chip is-live">사용 중</span>

Universal Graves가 기본 사망 처리 시스템입니다.

```text
사망
  → 무덤 생성
  → /graves에서 목록 확인 가능
  → 사망 위치로 이동
  → 무덤 상호작용
  → 아이템 회수
```

바닥에 수십 개 아이템이 흩어지는 바닐라 방식과 다르므로, 죽은 직후 먼저 **차원/위치와 `/graves` 목록**을 확인하세요.

## `/graves`

```text
/graves
```

자신의 무덤 목록을 여는 기본 명령입니다. 관리자에게 부탁하기 전에 먼저 이 목록에서 마지막 사망을 찾는 것이 좋습니다.

## 무덤 회수

일반적으로 무덤을 직접 열어 회수합니다. Universal Graves 자체에는 서버 설정에 따라 Shift + 빈손 사용으로 빠른 회수가 가능한 옵션도 있지만, **현재 서버에서 활성화됐는지 모르면 일반 상호작용을 기준**으로 하세요.

## 무덤이 이상할 때

- 목록에는 있는데 월드에서 안 보임 → 차원/좌표 확인.
- 열리지 않음 → 화면에 나온 보호/비용/권한 메시지 기록.
- 목록에도 없음 → 사망 원인, 시간, 차원을 관리자에게 전달.
- 복구가 필요하면 관리자는 Death Backup, InvView, Ledger, Bkups 등 별도 계층을 이용해 원인을 확인할 수 있습니다.

## 겉날개 + 흉갑

<span class="status-chip is-live">사용 중</span>

Elytra Slot을 이용해 흉갑을 일반 슬롯에, Elytra를 추가 슬롯에 동시에 장착합니다.

- 흉갑을 벗지 않고 비행 가능.
- 별도 필수 교환 단축키 없음.
- 인벤토리의 전용 슬롯에 Elytra를 넣어야 함.

→ [Elytra Slot 상세](/mods/elytra-slot)

## 인벤세이브권

<span class="status-chip is-plan">계획</span>

향후 경제 시스템의 중요한 돈 소모처로 추가할 예정입니다. 목표 동작은:

1. 사망 순간 세이브권 소지 여부 확인.
2. 조건이 맞으면 1장 소비.
3. 인벤토리 보존.
4. 세이브권이 처리된 죽음에는 중복 Graves를 만들지 않음.
5. 세이브권이 없거나 사용 조건이 아니면 기존 Graves 처리.

현재는 아직 구현 전이므로 **세이브권을 전제로 플레이하면 안 됩니다.**

## 사망 전 습관

- 장거리 탐험 전 JourneyMap 웨이포인트.
- 희귀 수납물이 가구에 있다면 재시작 안정성 검증 여부 확인.
- 네더/엔드에서 죽으면 차원을 기억.
- 큰 월드/모드 변경 전 서버 백업이 있다는 것을 운영 측에서 확인.
