# 생존 & 죽음

## 죽었을 때

Universal Graves 3.12.0+26.2가 아이템과 경험치를 무덤에 보관합니다. 현재 서버 config 기준으로 **XP 80%를 저장**하고, 타인 보호 타이머는 `-1`, 무덤 자동 소멸은 **14일**입니다. 만료되면 아이템을 드롭하도록 설정되어 있습니다.

사망 후에는:

1. 지급된 Grave Compass와 `/graves`로 위치 확인
2. 무덤으로 이동
3. 클릭해 GUI 확인
4. 빈손 + Shift 상호작용으로 빠른 회수 가능

[무덤 상세 →](/mods/graves)

## 겉날개와 흉갑

Elytra Slot이 별도 장비 슬롯을 추가합니다. 겉날개를 전용 슬롯에 넣으면 흉갑 슬롯을 비우지 않아도 됩니다.

[Elytra Slot 상세 →](/mods/elytra-slot)

## 벌목

이 서버의 FallingTree는 **Chopper 계열 인챈트가 붙은 도끼에서만** 작동합니다. 조건을 만족하면 통나무 한 블록을 부쉈을 때 감지된 나무를 즉시 처리합니다. 집이나 장식 통나무는 **Shift를 누른 채** 캐면 FallingTree를 잠시 끌 수 있습니다.

[FallingTree 상세 →](/mods/fallingtree)

## 서버 운영자 복구 수단

서버에는 Death Backup 3.6도 설치되어 있어 운영자는 사망 직전 인벤토리 백업을 복구할 수 있습니다. 이 기능의 `/deathbackup ...` 명령은 관리자 권한용이며 일반 플레이어 명령이 아닙니다. 무덤 자체가 이상하게 생성됐거나 서버 오류가 의심되면 사망 시각·좌표·아이템을 관리자에게 전달하세요.
