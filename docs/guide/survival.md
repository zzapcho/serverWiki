# 생존 & 죽음

<p class="page-lead">죽었을 때의 아이템 처리와 장비 슬롯이 바닐라와 다릅니다. 이 페이지는 첫 플레이 전에 한 번 읽는 것을 권장합니다.</p>

## 죽으면 어떻게 되나요?

<span class="status-chip is-live">사용 중</span>

Universal Graves를 사용합니다. 사망하면 바닥에 아이템이 흩어지는 대신 **무덤에 아이템이 보관**되는 방식입니다.

1. 사망 위치를 확인합니다.
2. 해당 위치의 무덤으로 이동합니다.
3. 무덤에서 아이템을 회수합니다.

관리자 측에는 별도의 복구 도구와 백업이 있지만, 일반 플레이에서는 무덤 회수를 기본으로 생각하면 됩니다.

## 인벤세이브권

<span class="status-chip is-plan">계획</span>

향후 경제 시스템과 연결된 서버 전용 아이템으로 추가할 예정입니다. 아이템을 소지한 상태에서 사망하면 조건에 따라 1장을 소비하고 인벤토리를 보존하는 방향으로 설계 중입니다.

구현 전까지는 **무덤 시스템이 기본 사망 규칙**입니다.

## 겉날개 + 흉갑

<span class="status-chip is-live">사용 중</span>

Elytra Slot을 사용해 겉날개를 흉갑과 별도의 슬롯에 장착할 수 있습니다.

- 흉갑 방어력을 유지한 채 겉날개 사용 가능
- 인벤토리에 겉날개 전용 슬롯이 추가됨
- 겉날개는 해당 슬롯에 넣어야 정상 동작함

::: tip 슬롯이 안 보이면
배포된 클라이언트에 Elytra Slot이 제대로 로드됐는지 먼저 확인하세요. 서버와 클라이언트 양쪽 구성이 맞아야 합니다.
:::

## 사용 모드

- Universal Graves
- Elytra Slot
