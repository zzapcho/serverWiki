# 낚시

<p class="page-lead">바닐라 낚시에 추가 어종과 보상이 더해져, 낚시 자체가 하나의 수집·경제 콘텐츠가 됩니다.</p>

<span class="status-chip is-beta">베타</span>

## 기본 플레이

낚시 방식 자체는 바닐라와 비슷합니다. 낚싯대를 사용해 물고기와 보상을 얻고, 잡은 아이템은 음식·수집·거래에 활용할 수 있습니다.

추가 어종이나 아이템의 정확한 용도와 제작법은 JEI에서 검색하는 것이 가장 빠릅니다.

## 경제와 연결

낚시는 농사와 마찬가지로 반복 가능한 생활형 수입원으로 설계합니다. 희귀 보상일수록 플레이어 간 거래 가치가 더 높아지도록 하고, 서버 상점이 모든 희귀품을 무제한으로 사들이지는 않게 할 예정입니다.

## 현재 알려진 문제

::: warning 네더/엔드 낚시 일부는 조정 중입니다
현재 서버 로그에서 Go Fish의 네더/엔드 낚시 loot table 일부가 Minecraft 26.2의 조건과 맞지 않는 경고가 확인되었습니다. 오버월드 낚시는 별도로 테스트하고, 네더/엔드 낚시는 수정 여부를 확인한 뒤 정식 가이드에 확정합니다.
:::
