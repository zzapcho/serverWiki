# 조합법 빠른 찾기

현재 클라이언트는 **JEI/REI 같은 레시피 뷰어를 사용하지 않습니다.** 그래서 플레이에 필요한 모드 조합법은 위키 안에서 보고 따라 할 수 있게 정리합니다.

## 모드별 조합법

| 찾는 것 | 바로 보기 | 형태 |
| --- | --- | --- |
| 세로 반블록 | [Vertical Slabs 제작법](/mods/vertical-slabs#제작법) | 세로 3칸 배치, 일부 석재는 석재 절단기 |
| SimpleOres 장비·블록 | [SimpleOres 제작법](/mods/simpleores#조합법) | 검증된 26.2 레시피를 기준으로 정리 |
| FallingTree | [FallingTree](/mods/fallingtree) | 제작 없음. 기능형 모드 |
| Terralith + Tectonic | [지형 가이드](/mods/worldgen) | 제작 없음 |
| MES | [MES 가이드](/mods/end-structures) | 제작 없음 |
| Universal Graves | [무덤 가이드](/mods/graves) | 제작 없음 |

## 조합법 표시 원칙

조합법은 가능한 한 **제작대/화로 슬롯이 그대로 보이는 그림형 도식**으로 제공합니다. 모드 버전과 1:1로 확인하지 못한 특수 레시피를 바닐라 패턴이라고 추측해서 추가하지 않습니다.

## 검색 팁

상단 검색은 띄어쓰기와 흔한 오타를 어느 정도 무시하도록 설정되어 있습니다. 예를 들어 아래 표현도 관련 문서를 찾도록 별칭을 넣었습니다.

- `세로반블럭`, `세로 슬랩`, `vertical slab`
- `미쓰릴`, `미스릴`, `mythril`
- `아다만튬`, `아다만티움`, `adamantium`
- `곡갱이`, `곡괭이`, `pickaxe`
- `나무베기`, `벌목`, `fallingtree`
- `템복구`, `무덤`, `grave`
