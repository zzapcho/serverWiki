# 조합법 빠른 찾기

현재 검수된 클라이언트 묶음에는 별도 레시피 뷰어가 없으므로, 플레이에 필요한 모드 조합법은 위키에서 실제 설치 JAR 기준으로 정리합니다.

## 모드별

| 찾는 것 | 바로 보기 | 검증 내용 |
| --- | --- | --- |
| 세로 반블록 | [Vertical Slabs](/mods/vertical-slabs#제작법) | 146 recipe JSON, 대표 3세로→6개 + stonecutting |
| SimpleOres | [전체 제작 패턴](/recipes/simpleores) | 202 recipe JSON을 카테고리별로 정리 |
| FallingTree | [FallingTree](/mods/fallingtree) | 기능형 모드, 일반 제작 없음 |
| Elytra Slot | [Elytra Slot](/mods/elytra-slot) | 슬롯 기능, 새 Elytra 제작법 없음 |
| Terralith | [월드젠](/mods/worldgen) | 선택형 recipe changes는 기본 false |
| Dungeons & Taverns | [구조물](/mods/dungeons-taverns) | harness 염색 16 recipe JSON |
| MES | [엔드 구조물](/mods/end-structures) | 제작 트리보다 월드젠/loot 중심 |
| Universal Graves | [무덤](/mods/graves#제작-가능한-빈-무덤) | Emptied Grave 실제 레시피 확인 |

## 원칙

- 다른 버전 레시피를 현재 버전에 복사하지 않습니다.
- 조건부 recipe는 필요한 외부 모드가 실제 서버에 있을 때만 현재 레시피로 안내합니다.
- 같은 패턴이 재료만 바뀌어 수십 개 반복될 때는 **패턴을 한 번 설명하고 적용 재료를 명시**합니다.
