# 조합법 & 제작 흐름

<p class="page-lead">위키에는 꼭 알아야 하는 조합 패턴과 특수 작업대 사용법을 설명하고, 설치된 정확한 버전의 전체 레시피는 JEI가 실시간으로 보여줍니다.</p>

## 가장 빠른 방법: JEI

| 하고 싶은 것 | 조작 |
|---|---|
| 아이템을 검색 | 인벤토리 오른쪽 JEI 검색창에 이름 입력 |
| 이 아이템은 어떻게 만드나? | 아이템 위에 마우스를 올리고 `R` |
| 이 아이템은 어디에 쓰이나? | 아이템 위에 마우스를 올리고 `U` |
| 모드 아이템만 보고 싶다 | JEI 검색에서 모드/아이템 이름으로 검색 |

::: tip 왜 모든 레시피를 위키에 그대로 복사하지 않나요?
서버는 모드 업데이트에 따라 레시피가 바뀔 수 있습니다. **JEI는 현재 설치된 실제 레시피 데이터를 그대로 표시**하므로 가장 정확합니다. 위키는 JEI만 보고는 이해하기 어려운 특수 조리·월드 조립·상호작용 흐름을 설명합니다.
:::

## Enchanted Vertical Slabs

바닐라 반블록의 가로 레시피를 **세로로 돌린 패턴**입니다.

```text
[ 같은 재료 ]
[ 같은 재료 ]
[ 같은 재료 ]
```

정확한 출력 수량과 지원 재료는 원하는 세로 반블록에 마우스를 올리고 `R`로 확인하세요.

## Farmer's Delight: 제작보다 중요한 조리 흐름

### 도마

1. 도마를 설치합니다.
2. 가공할 재료를 도마에 올립니다.
3. 레시피가 요구하는 칼/도구로 상호작용합니다.
4. 가공된 재료를 회수합니다.

### 요리 냄비

1. 스토브 등 적절한 열원 위에 요리 냄비를 둡니다.
2. 냄비 GUI를 엽니다.
3. 만들 음식의 JEI 레시피를 확인하고 재료를 넣습니다.
4. 완성된 음식을 요구되는 그릇/용기에 담아 회수합니다.

### 프라이팬

프라이팬은 조리 흐름에 사용됩니다. 어떤 재료를 사용할 수 있는지와 정확한 결과물은 JEI에서 해당 음식의 레시피 유형을 확인하세요.

→ [농사 & 요리 가이드](/guide/farming-cooking)

## Friends&Foes: 월드에서 조립/상호작용하는 것

일부 기능은 제작대 레시피가 아니라 **월드에 블록을 놓아 만드는 구조** 또는 몹 상호작용입니다.

| 대상 | 핵심 재료 / 힌트 |
|---|---|
| Copper Golem | 구리 블록, 조각된 호박, 피뢰침을 사용하는 조립 방식 |
| Tuff Golem | 응회암, 양털, 조각된 호박을 사용하는 조립 방식 |
| 몹 전용 아이템 | JEI `R` / `U`로 현재 버전의 정확한 제작법 확인 |

## 가구

Skniro's Furniture는 가구 종류가 많아 **가구 이름을 JEI에서 검색 → `R`** 하는 것이 가장 빠릅니다. 설치 후 우클릭으로 수납/조명/문 기능이 있는지 확인할 수 있습니다.

## 낚시 아이템

Gone Fishing에서 획득한 아이템은:

1. JEI에서 이름 검색
2. `U`로 사용처 확인
3. 제작 가능한 경우 `R`로 제작법 확인

순으로 보면 됩니다.

## 레시피가 안 보일 때

- 검색창에 아이템 이름 일부만 입력해 보기
- `R` 대신 `U`로 먼저 사용처 확인
- 서버와 클라이언트 모드 버전이 같은지 확인
- 모드팩에 직접 추가한 모드가 JEI 표시를 가리지 않는지 확인

::: info 향후 전체 레시피 카탈로그
실제 서버에 배포하는 **최종 모드 JAR 세트가 고정되면**, JAR 내부 recipe 데이터에서 버전 고정 레시피를 추출해 위키에 자동 생성하는 방식으로 확장할 수 있습니다. 그때도 JEI를 최종 확인 수단으로 유지합니다.
:::
