# 조합법 빠른 찾기

이 페이지는 거대한 레시피 복사본이 아니라 **어디서 만드는 법을 확인해야 하는지 바로 연결하는 인덱스**입니다. 중요한 조합법은 해당 모드 페이지 안에 함께 설명합니다.

## 모드별 조합법

| 찾는 것 | 어디서 보나요? | 비고 |
| --- | --- | --- |
| 세로 반블록 | [Vertical Slabs 제작법](/mods/vertical-slabs#제작법) | 세로 3칸 배치, 일부 석재는 석재 절단기 지원 |
| 주석·미스릴·아다만티움·오닉스 장비/블록 | [SimpleOres 제작법](/mods/simpleores#제작법) | 아이템 수가 많아 현재 JEI를 최종 기준으로 사용 |

## JEI로 정확하게 찾는 법

JEI는 **현재 클라이언트에 실제로 로드된 레시피**를 보여주므로 아이템이 많은 모드에서는 가장 정확합니다.

1. 인벤토리를 엽니다.
2. 오른쪽 아이템 목록 또는 검색창에서 아이템을 찾습니다.
3. 아이템의 **레시피 보기** 키로 만드는 법을 확인합니다.
4. **사용처 보기** 키로 그 아이템이 어디에 들어가는지 확인합니다.
5. 키가 작동하지 않으면 `설정 → 조작키`에서 JEI를 검색하세요.

많은 클라이언트에서 `R`과 `U`가 사용되지만 개인 설정이나 모드팩에 따라 달라질 수 있으므로 현재 조작키 화면이 최종 기준입니다.

## 검색어가 생각 안 날 때

위키 검색창에서는 이런 식으로 검색해도 됩니다.

- `세로반블럭`, `슬랩`, `vertical`
- `광물`, `광석`, `주석`, `미스릴`, `onyx`
- `겨울`, `계절`
- `엔드 구조물`, `mes`
- `죽음`, `템 복구`, `무덤`

정확한 모드명을 몰라도 비슷한 말과 영문 이름을 함께 찾도록 검색 별칭을 넣어 두었습니다.
