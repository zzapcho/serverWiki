# 처음 접속하기

<span class="status-chip">초기 가이드</span>

처음 서버에 들어왔다면 이 페이지부터 보면 됩니다. 최종 버전에서는 **접속 준비 → Discord 인증 → 필수 조작 확인 → 첫 플레이** 순서로 안내할 예정입니다.

## 1. 접속 준비

- 서버에서 사용하는 Minecraft / Fabric 버전을 확인합니다.
- 배포된 클라이언트 모드팩을 적용합니다.
- 서버 주소와 Discord 인증 상태를 확인합니다.

## 2. 접속 후 먼저 확인할 것

1. 인벤토리와 추가 슬롯이 정상적으로 보이는지 확인
2. 음성채팅이 연결되는지 확인
3. 지도 / 레시피 검색 / HUD 단축키 확인
4. `/wiki` 또는 `/guide` 같은 서버 도움말 명령어 확인

## 3. 처음 5분 체크리스트

| 항목 | 확인 |
|---|---|
| 서버 접속 | ☐ |
| 음성채팅 연결 | ☐ |
| 주요 단축키 확인 | ☐ |
| 경제 시스템 확인 | ☐ |
| 죽음/무덤 규칙 확인 | ☐ |

::: info
이 페이지는 실제 서버 온보딩 흐름이 확정되면 더 짧고 직관적인 '5분 빠른 시작' 문서로 다듬을 예정입니다.
:::
